## Scope

Owner: `src/pipeline_shards/retention_composer_limit_core.rs::apply_retention_first_p2_assertive_return_write_explicit_gate`
(population row 64, signature unchanged). Admission happens inside the owner's existing
candidate loop, before `make_retention_p2_inserted_chord_block`. The opening tag is parsed
structurally; text inside the note body never decides. An unparsable opening tag is refused.

The selected candidate set (`take(p2_requested)`) is unchanged; a refused candidate is not
replaced. The existing retained-occurrence collection also runs when no return was requested:
the early empty-row return is removed. All-refused and no-request states produce complete
retained rows, no generated rows, no write and no exact mutation receipt. Existing parsing,
range binding and sequence fingerprints prove the persisted retained occurrences.

The initial-render stage consumes the complete Split/Retained continuation for every active
Render/P2 boundary, regardless of render_written. The exact stage transition d6e77ec59a12d30f
-> d122561046e72a9c is the one admitted by accepted r1411. Both completeness and join are guarded
by the existing final_render_source_available: no separate Render source means the P2 owner
was skipped and its default empty audit is not an active P2 boundary. Master fallback is preserved.
All cardinality, unique input, pitch/chord topology, fragment, SourceEventId and AttackId checks
inside the join remain unchanged. Source/Attack identity is carried, never rank-reconstructed.
The existing omission filter is unchanged; retained witnesses describe surviving occurrences.

No new disposition is created. Fragments that are refused obtain the same accounting the
accepted parent already gives to every pruned fragment the owner does not select. If a
refused fragment were not covered by the certified prune set, the unchanged FinalChord
binder fails closed; refusal never turns an uncertified fragment into an admitted omission.

Not in scope: removing or rewriting print-spacing, activating concealed notes, changing the
prune, the omission certificate, the witness type or any other owner.
