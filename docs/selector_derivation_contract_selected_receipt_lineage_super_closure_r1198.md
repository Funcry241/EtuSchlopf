## Derivation from the accepted parent error class

The unchanged accepted `semantic_obligation_accounting_failure` contract says identity must be carried across boundaries rather than rediscovered. r1188 established opaque individual edit identity. r1192-r1196 then show that selected lineage gaps arise at exact causal boundaries even though edit accounting itself remains exact.

r1198 therefore closes only those accounting boundaries. It does not derive a new musical error class or a repair target. The productive owners already decide the state transition; the audit merely records the causal correspondence between the supplied complete parent and selected child states.

The final-artifact scope check is not a musical selector. It distinguishes the canonical configured final Render stream from renderer-feasibility shadow files so a shadow-local accepted candidate cannot be mistaken for a productive final-artifact selection witness.

The implementation remains within the frozen multiplicity contract `local_candidate_or_explicit_conflict_group`. The observation is downstream of existing productive decisions and remains AuditOnly.
