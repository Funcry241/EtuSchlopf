# Exact measure-context channel sharing

Parent: accepted r1426. One MusicMutation implementation contract under the
unchanged partwide renderer capacity error class. The r1426 diagnostic showed
zero merge attempts: complete channel classification denied missing direct rows
before a full candidate could prove preservation. The measurements are evaluation
only; this implementation uses no measured IDs or project-specific selectors.

The new positive proof preserves the exact complete measure/voice pitched input
across staffs for occurrences without a direct owner witness. No written beam
mark is admitted by this proof; no absence is promoted into a negative decision.
Every represented note's identity, bytes and spatial continuation stay equal.
Same-measure changes still require original positively bound cohort evidence.
Exact origin, protected resources, both original edge guards, lower-primary
reader predicates and the finite whole-channel search remain binding.

The shadow-rest flag is checked on its actual non-pitched inputs, rather than on
pitched-only source roles. Actual rests and their mapped/unmapped role values
stay equal; the three existing readers and their source files stay unchanged.
All source roles stay original. A retained original chord component may carry its
unchanged physical container relation regardless of print-spacing; independent
auxiliary members keep the original spacing admission rule.

Required synthetic controls: actual original owner and receipt, known and unknown
head cases, complete real search, foreign same-measure refusal, unknown written
beam refusal, actual rest-resource refusal, lower-primary predicate refusal,
same-role sharing, upper pitched role sharing, retained nonspacing original
container, source-origin drift, source identity and bystander checks. Independent
context duplication and source renaming cannot create or suppress a candidate.
