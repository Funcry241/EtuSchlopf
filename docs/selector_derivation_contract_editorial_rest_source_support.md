## Scope and authority

The accepted unbound_rest_context definition is unchanged. The repair restricts
the existing editorial proposal acceptance; it creates no rest, pitch, source,
course, writer or musical retirement authority. The actual authorized owner and
its exact receipts remain unchanged.

A disposable trial is reconciled through the existing material-lineage owner
under its representation-only effect contract. Acceptance requires the complete
multiset of independently bound pitched-source fragments to match the incoming
state, including opaque source/attack identity, actual measure-local temporal
support, pitch and grace class. Raw XML ordinal, technical labels and visibility
are not substituted for source ancestry. Missing authority, missing source or
attack ancestry, failed reconciliation, lost or duplicated support refuse the
proposal and preserve the current candidate. No XML scan mints a source identity.

The proof covers actual fragments, not only the endpoints of a sounding attack:
removing a middle tied fragment is not licensed merely because the first and last
fragment remain. An unrelated independent candidate or source cannot compensate
for a lost obligation. Candidate multiplicity and scorewide note counts are not
positive write authority. Existing source selection may still make its separately
bound decisions; this later editorial rest proposal cannot silently overrule them.

The late-entry first-bar case is only a witness. The class and guard do not test
an onset value, measure number, hand or note count. Independent occurrences in
different measures and renamed labels remain independently protected. The existing
editorial audit and trial machinery remains present; only unproved musical loss
is refused before adoption. No report counter is rewritten to conceal a loss.

## Evidence boundary

Regression tests use real MIDI seed, source selection, arrangement, bound material
lineage and the actual editorial full-rest owner. They cover an unchanged valid
trial, actual source retirement, fragment loss/duplication, label/ordinal changes
and missing ancestry. Runtime cases separately check different hands, delay values,
measure positions and independently duplicated delayed entries.

Native acceptance and full original-corpus/PDF comparison of r1537 remain pending.
