## Definition and limits

This class describes a representation-ordering defect at an existing decision
boundary. It does not define a new preferred beam pattern. Membership requires
a comparison under the same existing structural predicate and an actual
authorized transition. A final screenshot, similar pitch/time geometry or a
count of missing beam tags cannot establish occurrence continuity or authority.

The relevant connection has not yet been written. This differs from the accepted
beam_connection_voice_separation class, where an actual or proposed connection
would be separated by a later simultaneous voice assignment. A rest that was
deleted earlier belongs to its separate rest-elision class; absence of a rest
alone does not establish this ordering defect.

A positive structural predicate result is only a candidate, never proof of a
musical course, a rest's responsibility or permission to connect notes.
Unknown or contradictory canonical context remains Unknown. A serialization
label is not a musical identity. Existing-rest ancestry and any proposed
subdivision must retain their actual origin; a generic transformation receipt
must not be promoted into an independent rest-role decision.

## Necessity review

The earlier real owner evaluation is necessary to distinguish ordering from a
rule that never considers the connection. The authorized representation
transition is necessary to distinguish materialization from an arbitrary
counterfactual rewrite. Preserved pitched timing isolates representation from
changed musical content. The unchanged predicate isolates its input dependence
from a new musical preference. The absence of a later authorized decision
explains why the ordering difference survives into released notation.

These features apply with unknown new scores and arbitrary local multiplicity.
No exact staff, label, pitch, duration, rest partition count or corpus location
is part of the class. An independent duplicate creates an independent local
obligation; a global winner or scorewide singleton cannot confer authority.

## Separate later repair scope

This definition admits no reader, writer, issuer, pass relocation, earlier
FinalChord projection, additional E050 invocation or change to receipt semantics.
It selects neither an early canonical-context read nor a later owner invocation.
Any implementation must reference this byte-unchanged contract from an accepted
parent and separately justify its actual musical decision, canonical role and
course context, complete occurrence binding, rest ancestry, exact receipt,
adoption and all intervening/final voice assignments.

The existing canonical_rest_context_v1, role_occurrence_binding_v1 and
beam_extension_evidence_contract_r1474 contracts remain unchanged. Missing
rest responsibility cannot be inferred from a planned final XML voice label.
Preserving the original rest is not permission to author a beam through it.

Required future synthetic probes include canonical context present/absent,
stale or ambiguous occurrence binding, missing/hidden/foreign-responsibility
rests, exact splitting versus holes/overlap, beat and role/staff boundaries,
chord attachments, unchanged sounding material, rejected/discarded adoption,
late conflicting assignments, relabeling, relocation, time scaling and
independent duplication. Real score fragments are evaluation inputs only.
