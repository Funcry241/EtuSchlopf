## Derivation and authority

The accepted parent contains the unchanged consumer-order error definition and
the exact E057 optional immutable canonical-input admission. This implementation
uses the existing E057 owner, its original receipt wrapper and the existing final
Render-source closure. E050 remains beam-only. No new group, rest, rest role,
voice assignment, writer root, issuer, raw file filter or sink is introduced.

Connection selection starts from the live original owner course, never final
tags or musical resemblance. Current occurrence positions are bound through
the inherited source/attack/fragment witnesses. Numeric labels and byte offsets
are locators and equality checks, not musical decision authority. Unknown,
stale, missing or contradictory context grants no exchange.

The first supported operation exchanges whole contiguous pitched/chord units
with unique existing duration-identical forward nodes in a coherent existing
rest traversal. Explicit staff/voice ownership is required for placeholders.
Interleaved chord context, orphan attachments, overlapping notes or ambiguous
rest traversal are declined. These restrictions establish exact resource and
cursor preservation; they do not isolate a known score location.

## Independence and transport

Disjoint source/destination units are independent even within one measure:
each exchange consumes the same time at each affected slot. Shared resource
proposals are rejected together; independent proposals remain eligible. No
global singleton, winner or whole-score ambiguity veto owns authorization.

The bound plan retains the exact pre-state and original projection epoch.
Equal XML from another epoch cannot substitute for that provenance. E057 alone
materializes the original prebound bytes. A separate verifier checks its actual
original preserving receipt, every changed and unchanged byte, all timed note
resources and chord attachments. It transports every affected physical ordinal,
including unmoved occurrences, while retaining source/attack/fragment keys,
original membership and origin, and the phrase-origin identity.

The ordinary order-preserving transport remains strict. The dedicated exchange
transport maps the existing receipt, complete beam surface and every live
connection resource through the actual operation. Final canonical validation
then uses the unchanged actual final voice plan. A trial continuation does not
become Main evidence until the existing source sink successfully adopts the
exact candidate and its witnessed readback. Shadow and rejected candidates
cannot supply Main evidence.

input, canonical transport, successful/failed/wrong-readback Main adoption,

Known score locations are evaluation only. Endpoint tags and scalar event
multisets alone cannot prove canonical identity or successful PDF continuity.
