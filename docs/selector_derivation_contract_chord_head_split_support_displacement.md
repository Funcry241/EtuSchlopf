## Frozen structural error class

Status: definition only; no new classifier, selector, issuer or writer.
ChangeClass: KodexOnly. Parent: accepted r1350, version 0.10.1839.

An existing physical chord cohort contains a cursor-advancing non-chord host
and one or more following chord members. The member's physical start is resolved
against that host. A representation owner replaces the host with sequential
non-chord fragments. A dependent member is not transported through that change
with conserved source-bound represented support. Readback consequently resolves
the member against a later host fragment and changes its original interval.

The class is the changed represented support caused by the host replacement,
not simply the presence of an unsplit member or multiple head fragments. An
equivalent, explicitly authorized cursor representation that conserves the
member's interval is outside the error class. A suspicious shape alone is not
a proven mutation or repair license.

The cause is local XML cursor/host dependence. It does not depend on musical
course equality, staff, voice label, visibility, pitch, independent candidate
count or a particular metric duration. A hidden pitched member is sounding
material. A physical rest host with hidden pitched members has the same cursor
dependence; pitch absence in the host cannot discharge their obligations.

## Why every feature is causal

The physical host relation supplies the dependency. Sequential replacement
changes the stream's most recent non-chord onset. The unchanged dependent
member consumes that new onset. Exact source-bound before/after support
distinguishes displacement from a valid equivalent representation. Removing
any piece name, measure label, pitch, renderer result or visibility annotation
does not remove this mechanism.

Neither host/member membership nor source identity may be reconstructed after
the write from coincident pitches, geometry or labels. Physical cursor readback
checks the transported origin; it cannot mint that origin or musical authority.

## Discovery and actual-owner evidence

This class was discovered while transporting r1350's already issued seed
courses through the existing initial arrangement and visible-rhythm ledger.
A synthetic generator fixture creates two coincident upper-staff pitches plus
the deliberately empty lower presentation. The existing normalization divides
the upper host into beat fragments while leaving its physical chord member
after the last host fragment.

The course-custody prototype was admitted by the unchanged early Take gates.
Its actual-owner tests compiled under Rust 1.98.0. Five passed; the chord-support
test failed at exact interval readback. That failed prototype is not this Take
and grants no authority. No real corpus file was used to define the class.

The companion foundation gives synthetic cursor algebra and invariance probes.
These are policy models, not runtime tests or a full pipeline proof. Future
classification must measure the complete corpus only after this definition is
accepted, without changing these features to isolate a known example.

## Separate future repair prerequisites

Any productive repair must consume this unchanged accepted definition under a
separate repair-scope contract. It must have complete incoming physical
host/member inventory and creation/source ancestry before normalization, with
exact support for every member. Unknown imported material remains protected;
absence of provenance cannot license deletion, restification or inferred roles.

The existing representation owner must plan a complete local transaction that
preserves every represented source interval, attack, disposition, staff action,
tie obligation and physical host dependency. Interleaving consistently tied
host/member fragments is one possible realization when independently supported
by the actual cohort domain. It is not automatically valid for unequal support,
grace material, existing ties, hidden rest hosts or cross-staff presentation.
Equivalent explicit cursor realizations require their own existing typed
authority. No new legacy delegate or generic XML repair facade is admitted.

The owner must capture fragment creation and ancestry at actual materialization,
then prove exact physical readback, complete inventory and conserved licensed
coverage before adoption. A musical course license does not itself permit an
XML write. Independent cohorts receive independent local decisions; a global
first-match, uniqueness cap or renderer budget cannot select a repair.

Required actual-owner tests include visible and hidden members, rest hosts,
metric splitting, equal and unequal supports, leading silence, existing ties,
staff transitions, imported Unknowns, refusal/rollback, and independent cohort
duplication. Renaming, relocation, label changes and metric scaling must preserve
the same classification when their cursor/source relations are preserved.
