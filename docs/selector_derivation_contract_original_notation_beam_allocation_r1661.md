## Necessary written-edge condition before full projection

Any admitted sharing projection must retain the same occurrence keys, source
identities, staffs, onsets, physical chord relations and all non-voice bytes.
The existing written-edge checker groups physical heads in one staff/measure/voice
in onset order. Thus an existing edge between two unattached heads cannot survive
if the proposed labels differ. It also cannot survive an unattached head strictly
between those onsets on the proposed lane unless that head carries `continue`
at the same beam level. Begin replaces the open chain; end closes it before the
second endpoint; absent/other states cancel it.

These are necessary conditions of the unchanged preservation predicate. Their
contrapositive can reject a proposal before running the full XML projector.
All other cases, including equal onsets, chord members, non-pitched heads and
unknown bindings, still reach the complete existing proof. Changing any of the
assumed preserved fields cannot rescue a proposal: it would violate another
unchanged mandatory preservation check. Per-lane onset indices make the proof
local to the actual affected lane, without corpus address or acoustic duration.
The optimization grants no new admission and does not truncate the search.
Synthetic enumeration compares the implication against the unchanged full
written-edge function over every binary label assignment, interruptions, hooks,
relocated scopes, equal onsets, attached heads and independent duplication.

## Necessary unchanged-source connection condition (r1662)

Any admitted projection preserves all occurrence identities, non-voice bytes,
physical chord attachments, staff and onset. Substituting the proposed labels
into the baseline occurrence readback therefore gives the same written edge
relation, provided head onset order is unambiguous in every proposed lane.
Ordinal changes cannot affect distinct onset order. Existing chord membership
is interpreted by the unchanged written-connection function, not by a new rule.
If that relation changes an edge between two unmoved sources, the existing
unmoved-connection guard necessarily refuses the actual proposal. Changing any
of those premises in the actual projection already fails another mandatory guard.

This contrapositive is an early refusal only. Missing labels and equal head
onsets produce unknown and continue through the full projector. No candidate is
admitted by this computation. Synthetic label enumeration checks both ordinal
orders, relocated identities, changed and unchanged edge sets and ambiguous-onset
fallback. The accepted causal class remains byte-identical. The native corpus
must still demonstrate identical output before the refactor is accepted.
