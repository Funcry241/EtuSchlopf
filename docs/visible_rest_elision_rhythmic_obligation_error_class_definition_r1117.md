r1117 performs only the required `causal_class_first_v1` foundation step for the newly isolated visible-rest-elision defect class. It freezes the class before any selector-sensitive classification or repair code is changed.

The frozen contract is:

`docs/selector_derivation_contract_visible_rest_elision_rhythmic_obligation.md`

This take does not change MusicXML, Render-MusicXML, PDF output, productive rest selection, writer reachability, thresholds, scoring, corpus targeting, or release behavior.

## Frozen causal error class

The class is named `visible_rest_elision_without_bound_rhythmic_dispensability_proof`.

A member requires a concrete already-visible rest carrier, a productive proposal to make that carrier invisible or cursor-only, and absence of positive evidence bound to the carrier and its complete interval that the rhythmic obligation is dispensable in the resulting notation.

Technical serialization shape, activity somewhere else on the same staff, raw voice labels, preserved sounding events, correct MusicXML cursor movement, or parseability are not by themselves a dispensability proof.

A positive neighboring case remains allowed when independent evidence proves one of the following without witness-specific context:

- the same musical responsibility continues and remains legibly represented over the affected interval;
- a semantically equivalent redundant visible representation survives the accepted mutation;
- the carrier is positively established as a technical helper with no independent rhythmic obligation.

If such evidence is absent or contradictory, the future eliding owner must preserve the already visible carrier. `Keep` means preservation only. It does not authorize exposing hidden rests, synthesizing rests from arbitrary forwards, filling every staff to the bar duration, or introducing a new voice-analysis architecture.

## Scope boundary

The general musical invariant is broader than any first repair. This take does not claim that every productive rest-elision path is defective or that every such path will be changed next.

The intended next repair investigation is deliberately local: determine the first actually adopted productive transition in the existing RestOnly path and, only if confirmed, restrict that existing owner so it cannot remove a visible rest merely because the same staff contains visible pitched activity elsewhere in the measure.

A visually similar corpus location is not a required co-member of the first repair scope. Different loss paths may remain separate defects.

## Explicit exclusions

The class is not defined by Etude identity, measure number, page/system position, 4/4 meter, 96 divisions, 384 ticks, exact rest duration, exact note count, staff number, numeric voice label, pitch/register pattern, or rarity/uniqueness in the current corpus.

The current corpus is evaluation evidence only. No real Etude fragment is made normative by this take.

## No corpus measurement and no repair authority

`CorpusDistributionPurpose` is `not_yet_measured`. r1117 adds no classifier, selector, repair scope, MusicMutation, writer, threshold, weighting, or new productive data path.

A later selector-sensitive repair take must consume the frozen contract byte-unchanged from the accepted r1117 parent and may narrow scope only for independently justified authority, safety, materialization, or preservation reasons.

No new proof architecture is implied by this foundation take.
