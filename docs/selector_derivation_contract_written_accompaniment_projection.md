Der Notensatz kann eine vollständige Begleitgruppe im unteren System
darstellen, sofern sie dort weniger Hilfslinien benötigt und die Töne vom
Bass getrennt bleiben. Die metrische Abdeckung bleibt durch den über
beide Systeme geführten Stimmenverlauf erhalten.
