The accepted parent definition stays byte-identical. This implementation is a
bounded repair inside it, not a new error class and not a full formula optimizer.
All alternatives of a score conflict because they replace that same whole layout;
independent scores have separate state and cannot select or suppress one another.
The existing round limit is unchanged. The optional trial is scheduled after
existing nearest-lower-page refinement stops. One transfer limits the changed
page boundary and enables direct source, course and physical before/after checks.
No system is split, merged, reordered or emptied, and no page is added or removed.

The estimate only schedules a shadow. It uses observed system envelope heights
and bound source page geometry, not a new demand/capacity rule. Every actual
layout is still written by the existing materializer and promoted by the
existing original joint-plan owner. Only actual fresh improvement authorizes
adoption. Supported rejection or unknown optional physical evidence retains the
incumbent; missing renderer output, changed consumer and collapsed boundaries
remain errors under the old checks. The physical trial does not create horizontal
no-goods. Register-reader evidence is observed only for confirmed selected plans.

The new native reader admits a deliberately narrow unrotated Qt/Identity-H
TrueType profile. It requires embedded glyph bounds and advances, decoded text,
complete supported paint operators, opaque black ink and rectangular clipping.
Cubic path control hulls and stroke pads conservatively enclose ink. Unsupported
fonts, glyphs, transforms, clipping, paint, transparency or missing metrics yield
unavailable evidence, never invented distances. Metadata titles/part names are
excluded only by their declared XML role and position, and native bold page
folios by their non-musical header role. System measures and pages are bound by
the existing complete readback and staff-cell owner. Visible notehead counts
must agree with the immutable source course. Connected glyph/staff anchors bind
beams and stems together before gap measurement; ambiguous ownership rejects
that physical observation. Musical identity is carried by the source, not minted
from PDF similarity. Glyph multiplicities must match per unchanged system.

A whole vertical envelope can overlap another at different horizontal positions.
The score therefore compares conservative component gaps only where horizontal
projections overlap. No observed corpus gap is installed as a minimum. Positive
separation is a non-overlap proof condition, not a millimetre calibration.
Paper, explicit margins, scale and distance defaults are not modified.

After final source adoption the same actual consumer is required again. The
existing oracle still uses exact invocation equality. For the final output only,
input/output operands are explicitly rebound by reconstructing both actual
commands from the unchanged original variant factory; the executable and selected
variant must match and foreign paths or unknown commands cannot authorize it. A fresh
complete physical observation of the finally consumed representation must retain
the pair gain and positive system separation. Failure blocks the new adoption;
there is no unproved fallback file, discarded note or weakened release verdict.
Independent existing musical, phrase, identity and register obligations remain
with their original owners. The automatic planner currently carries no separate
typed musical page-turn obligation; geometrical measurements do not assert
musical page-turn quality or override an independently bound obligation.
