# r78 Console Bootstrap Role Color Recovery Contract Closure

Parent: real-committed `0.10.1839 r76`.

r77 was a SecurityOnly candidate that successfully demonstrated the compact colored Take-Bootstrap interactive presentation, but its Reexec was rejected by the architecture build gate and the Take transaction rolled back completely. The cause was narrow and presentation-bound: the r77 Watch-project success line replaced the canonical technical recovery-contract marker `WATCH-PROJECT-PREFLIGHT GRUEN` with a typed interactive `OK` projection. The semantic Watch pre-copy Cargo test itself remained present, but the architecture gate intentionally requires the canonical technical evidence marker as part of the transactional recovery contract.

r78 preserves the r77 segment renderer and the r76 quiet Interactive-vs-Technical sink split. The interactive Watch-project success projection remains compact and typed (`LocalStatus::Ok`), while the canonical `WATCH-PROJECT-PREFLIGHT GRUEN` marker is emitted separately as `TechnicalOnly` evidence. This keeps display text out of presentation-semantic inference while preserving the stable security/recovery evidence surface expected by `identity_debt_build`.

The Bootstrap renderer remains per-stream and policy-driven: the product prefix is muted, `take` is cyan, local OK/COMMIT is green, warning/ROLLBACK yellow and errors red. Redirected stdout/stderr and `NO_COLOR` remain plain; stdout and stderr capabilities are resolved independently. The technical Take log remains plain and complete. No global Windows color command, `cmd /C color`, Console mode mutation or cross-process inherited color state is introduced.
