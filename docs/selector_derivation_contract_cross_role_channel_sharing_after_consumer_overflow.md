## Scope

role-separated partition. Whole guest channels move, smallest registering load
first, into a same-staff host channel of another role. SemanticDifferent and

witnesses only. It does not deny a complete proposed partition before the following
independent positive preservation proof can run. Original capture document,
complete canonical locators and a valid original capture scope must still match;
a missing/default origin never admits a candidate.

A touched occurrence without a direct beam witness may be preserved only if:
- both bound projections carry no written beam mark on that occurrence and have
  supported note types;
- the complete ordered pitched input of its entire measure and technical voice,
  across both staffs, is identical before and after up to the technical voice;
- every key comes from the exact producer output receipt, with unchanged source,
  attack, fragment, materialization kind and ordinal, staff, onset and note bytes;

This proves equality of the input to the measure-scoped beam consumers, including
all staff/voice/beat subgroups. It grants no original beam ownership, negative

Unknown written beam marks cannot use it. Existing original-owned-state checks,
written-edge preservation, bystander edge equality and every new-pair/new-edge
original positive cohort check remain mandatory. Full source/attack correspondence,
spatial continuation and complete-class preservation are checked for every note.

This broadens enumeration only, not musical compatibility or authority.


## Whole search first, deterministic distributed candidate

The complete accepted whole-channel search runs first, with distribution disabled
at every recursion depth. Its successful result is returned immediately. Only
when this entire search is exhausted does a separate pass begin with fresh
memoization. No failed intermediate branch can start distribution in the first
pass. The original captured scope and baseline projection are reused.

The additional pass constructs one deterministic complete distributed candidate
per eligible guest: components keep the existing least-options ordering and
choose the first conflict-free, predicate-compatible host in the existing host
order. It does not enumerate the Cartesian product of host options. This is a
candidate construction algorithm, not a threshold, time budget or completeness
claim. A failed candidate proves no impossibility. Whole classes and connected
measure components remain intact. The unchanged full proof alone admits output.

A synthetic 48-component traversal checks one distributed attempt and a host
predicate count bounded by components times available hosts. Existing successful
whole-channel producer/search tests assert that the distributed phase never
starts. Complete source/receipt binding, all conflicts, reader predicates and
beam/rest/bystander checks remain unchanged.
