## Repair-scope derivation

The accepted parent r1126 already defines `visible_rest_elision_without_bound_rhythmic_dispensability_proof` in `docs/selector_derivation_contract_visible_rest_elision_rhythmic_obligation.md`. r1136 consumes that contract unchanged.

The diagnosed early collision decision has no final-voice dispensability proof, so r1136 retires only that whole-object elision. The existing canonical `project_final_chord_encoding_plan` already owns physical final voice-label materialization for the Master. r1136 extends that same owner with a rest-only interval projection activated only on the canonical bound plan; it does not add an external repair caller.

Rejected r1134 proved that cursor-duration conservation alone is insufficient when the selected rest object is also a physical chord anchor. `anchor_index` is therefore a required topology-safety exclusion before any interval edit is planned.

## Causal-feature necessity review

1. Existing visible rest identity is necessary because the accepted class protects existing rhythmic information rather than authorizing new rest creation.
2. Final physical staff and voice labels are necessary because pre-serialization raw voice labels can differ from the resulting serialized lane.
3. Visible positive-duration pitch in that same final lane is necessary because only represented sounding occupancy can establish local redundancy.
4. Cross-voice and hidden pitch are excluded because neither proves another visible voice's rhythmic silence redundant.
5. Interval subtraction is necessary because proof for one occupied subinterval does not prove the rest of the carrier dispensable.
6. The existing metric-rest planner is necessary so preserved silence is rewritten only in already-supported metric forms.
7. Physical chord-anchor ownership is necessary because inserting a `<forward>` inside the replacement sequence resets anchor state and can move a following chord-member pitched occurrence.
8. Byte-topological provenance carry is necessary because an authorized rest-only replacement can move later note byte ranges without changing their musical identity; exact final range validation remains authoritative.
9. Local candidate scope is necessary because the causal decision does not depend on corpus frequency, discovery order or global candidate count.
10. Ambiguous overlapping visible rests and whole-measure rests are excluded because r1136 does not acquire those ownership domains.

## Prior runtime identity evidence

Rejected r1135 reached the real program run and passed the chord-anchor pitched-timeline invariant, then failed because a surviving pitched-note provenance row still carried the pre-rest byte position while the final XML contained the same pitched note at a byte-shifted position. r1136 does not broaden repair scope in response; it only transports already-established provenance through the exact rest-edit deltas and continues to require exact one-to-one pitched coverage in the final XML.

## Multiplicity and relocation

The synthetic StructuralWriteAuthority test constructs measure identity from runtime parameters, not a corpus locator. It checks beginning-overlap projection, cross-voice exclusion, hidden-pitch exclusion, independent duplication, early-plan non-authorization, pitched-timeline preservation, and chord-anchor exclusion.

Duplicating an independent eligible carrier in another synthetic measure duplicates the local edit without changing the first carrier decision. Relocating the same causal structure to another synthetic measure leaves the rule unchanged.

The chord-anchor probe is likewise synthetic and relocatable: it proves that a visible rest with a parsed chord-member dependent is not selected, independently of measure number, pitch, staff label, or corpus occurrence.
