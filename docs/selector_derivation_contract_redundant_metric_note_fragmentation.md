## Definition before repair selection

The defect class is the replacement of an already adequate single metric value
by avoidable fragments solely because the normalizer visits every beat boundary.
The class is independent of any particular pitch, hand, measure number or test
file. Synthetic examples informed the investigation; no real-corpus distribution
has been used to define or narrow this class.

This definition does not declare every long value adequate. Separate attacks,
intervening rests, metric position, notation obligations, chord membership,
voice/course ownership and outer tie endpoints can require another spelling or
refuse a proposed preservation. Repair admissibility remains a separate question.
A held whole-bar tone in ordinary 4/4 is one witness, not the class definition.

A later repair may preserve the existing occurrence before unnecessary splitting.
It may not merge existing occurrences or infer shared source/attack identity from
matching pitches, duration sums, labels or visual proximity. The existing owner,
source ancestry, exact interval, staff, voice and downstream obligations remain
binding. Existing genuine splitting and its safety checks remain present.

This Stage A changes documentation and Take identity only. It contains no
classifier, predicate, repair scope, musical writer or runtime change. The later
implementation must reference this exact unchanged file from its parent tree.
The separately observed articulation, outer-tie and unowned-chord defects are
not repairs authorized by this definition.
