The inherited error class remains sounding-only overlap forcing technical
channel separation. This implementation composes two existing constraints at
the source allocation boundary, before labels and fill rests are materialized.
The original component quotient is retained. Each component is considered once
for existing destinations ordered by their first producer occurrence. Only an
earlier destination may be used. Every moved source strictly decreases its
fixed initial channel rank, proving termination even when a technical channel
contains unrelated resources and therefore cannot be removed as a whole.

The repair selector is deliberately narrower than the error class: it requires
positive independent notation-origin evidence for every source in the component and the destination occurrences in its
written footprint. The footprint is derived only from sealed source locators.
At least one destination source must be present there; absence never proves
a common line. A technical channel may reuse its name in another independent
written frame without identifying those musical lines. Missing or conflicting origin, written overlap, unchanged source
rest collision, unproved cursor use, changed chord attachment, changed tie or
grace binding, changed role, changed original-owner edge or written beam pair
refuses the step. Unknown evidence retains the admitted baseline. Musical
identity is never inferred from a time gap, presentation role or acoustic lane.

The independent-candidate duplication probe repeats the causal input under
fresh identities and in a second measure on an independent staff. A duplicate
sharing technical-channel resources separately verifies the inherited safe
refusal before this refinement; this take does not weaken that earlier check. A real written overlap, distinct
original notation line or missing origin must each prevent reuse.
The original group must still remain united in those negative cases.
No late alignment, bridge withdrawal or beam writer is changed. A native
corpus comparison remains required to establish the final score effect.

A second original component sharing the technical guest channel but carrying a
different independently captured notation line must remain in place while the
affected component reuses the earlier channel. Written overlap decisions use
WrittenInterval values only. Sounding evidence is neither shortened nor erased.


## Written scope of the origin certificate

A common original notation voice is a source-line fact. Sharing a technical
channel across disjoint written frames does not assert that fact. The prior
implementation quantified over every source ever assigned to the destination
channel, allowing an unrelated earlier frame to veto a local source equality.
The corrected premise quantifies over the sealed component and destination
sources represented in its written footprint. Their origin must still be
complete and identical. A source with fragments in several frames remains a
whole source; all its origin entries must agree. The entire-proposal occupancy,
rest, role, chord/tie, written-edge and ordered-owner-edge checks are unchanged.
This changes the domain of an origin assertion, not the set of conserved facts.

The added synthetic counterexample places a different original voice in an
earlier independent frame of the same destination channel. It verifies that
the old whole-channel origin premise fails, the scoped premise succeeds, the
outside assignment is unchanged and the actual owner-backed component reuse
succeeds. A destination with no local occurrence is separately refused. The
existing different-origin-in-the-same-frame counterexample remains refused.
