## Causal definition

This error class exists when a beam continuity already required by the canonical notation/beam authorities is visibly lost in the final product because the same semantic notation line is represented by multiple technical serialization voices/channels that the renderer treats as separate beam containers.

The class is deliberately effect-specific. A technical voice/channel split without a loss of required visible primary-beam continuity is not a member of this class. Conversely, a visible beam break with an independently valid canonical beam boundary or semantic notation-voice boundary is not a member of this class.

The class definition does not state how many members exist in the corpus and does not require any member to be unique. Corpus distribution is intentionally unknown at this stage.

## Necessity review

1. Canonical primary-beam continuity is necessary because without an authoritative expectation of continuity there is no beam-fragmentation defect to explain.
2. A proven common semantic notation voice is necessary because separate semantic voices may legitimately own separate visible beam structures.
3. A final technical serialization partition is necessary because this class is specifically about representation splitting across technical voice/channel boundaries.
4. A final visible continuity loss at that partition is necessary because representation splitting that renders correctly is not a product error of this class.
5. Absence of an independently authorized beam/notation-voice boundary is necessary so that a legitimate musical break is not misclassified as technical fragmentation.

## Evidence requirements for later classification

A later classifier must bind exact event occurrences across the canonical beam evidence, notation-voice evidence, final serialized representation, and final renderer/readback observation. Pitch/onset/staff/voice similarity or spatial proximity is not a substitute for occurrence provenance.

A later classification take may measure or falsify this definition, but may not modify it using the observed corpus distribution. Any future repair scope must be a separate later take and may narrow this class only for independently proven authority, safety, materialization, or invariant reasons.
