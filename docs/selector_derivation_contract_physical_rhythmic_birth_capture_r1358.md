## Actual prerequisite and scope

The actual Atomic producers return their original EXACT receipts, but previously
discarded physical birth evidence. The downstream visible-rhythm normalizer
also returned only a block receipt and ordinal fragment rows. Later custody
cannot retroactively issue identities from either XML or those rows. This cut
captures identities at the existing physical creators and carries their original
capture through the actual candidate handoff. It changes no musical decision,
renderer arguments, frozen signatures, conservation policy or adoption rule.

The restification batch (#39) captures each changed physical replacement. Its
patch wrapper (#63) carries those same identities into its outer receipt and
does not remint them or attach both receipts for one transition. Safe transfer
(#3) captures its distinct source rest and inserted pitched representation using
its actual replacement/insertion arithmetic. Equal-looking executions remain
distinct. Scalar moves create no occurrence and issue no birth.

VisibleRhythm (#52) captures metric fragments when emitted and proposed gap-rest
objects when appended. Existing unsplit objects receive no fresh identity.
The actual serialization carries fragment locators through subsequent rest
insertion. A rolled-back insertion publishes no proposal births; retained metric
fragments keep their actual identities. Measure assembly transports both input
references and output locations with its actual append offsets. A changed
type-only block has an empty birth inventory and its exact execution binding.
Unchanged states need no new capture. Initial GENESIS arrangement does not use
this BLOCK capture path and its original course births remain independent.

The normalizer returns its actual capture in the result object. Compound-patch
handoff binds that capture to the original BLOCK identity in OwnerReceipts.
The frozen BLOCK type and its entire impl remain byte-identical to the parent.
The original receipt sequence carries it through compound crop/normalizer
patches as well as ordinary EXACT patches. Atomic candidate construction validates
the sequence and retains the capture with its candidate. Unsupported or missing
capture boundaries increment the candidate's explicit Unknown capture count;
they cannot create ancestry or silently become complete. The original Master
adoption still consumes the original receipts and remains fatal on missing
coverage. Observation never replaces that decision with candidate rejection.

## Authority boundary

These are physical birth identities, not canonical source/parent identities,
courses, lifetime declarations, role segments or new rest authorization. An
input range is a bound transaction reference; it is not a reconstructed parent.
No numeric identity value, XML label, source position or fingerprint decides
membership, priority or a musical write. Existing gap rests are recorded as
the existing writer's physical creations with unbound musical context, not
newly licensed Primary silence. Source/course binding and later occurrence
continuation remain required independently. Historical captures are not a
complete final-state inventory and cannot authorize channel reuse.

Sealed existing creator capabilities alone can issue these identities. Snapshot
bindings validate exact physical input/output objects. Actual-owner synthetic
tests exercise independent duplicates, UTF-8/renaming, both insertion orders,
split/gap emission, BLOCK handoff, the patch wrapper and real Atomic candidate
adoption. A missing original receipt remains fatal at that same receiver.
No real corpus data supplies normative fixtures or selectors.
