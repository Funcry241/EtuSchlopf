Original beam groups describe musical membership. A source attack shared by
two such groups forces one simultaneous allocation decision. Each group
keeps its own local beam grammar and renderer observation. The existing
voice allocator checks the effect of proposed labels on all involved
resources and bystanders before the existing atomic scalar writer applies
the Render assignment. If the number of missing adjacent edges exceeds
the number of same-label adjacent pairs in the same ordered group, at
least one missing edge crosses a serialized voice boundary.

The PDF binder accepts a displaced singleton head only when a conventional
neighbor of the same onset supplies a distinct physical stem on the same
axis. The two nearby stem endpoints lie in disjoint bands around adjacent
staff positions. The existing chronological and exclusive attachment
constraints still determine whether a complete assignment is unique.

Take acceptance uses the ordinary final renderer output. For each affected
local origin, the audit binds the canonical source occurrence identities to
the corresponding ordered notes and checks every required neighboring pair
in the final PDF. The existing release and writer paths retain their authority.
