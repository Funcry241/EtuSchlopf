must still bind the actual pre-FinalChord producer bytes. Group membership and
positive/negative decisions at every owned beam level come from that real
execution. The canonical source locator supplies the existing FragmentId,

member invalidates the complete group; removing a member cannot shrink it into
a successful closed subgroup.

at its authenticated freeze boundary. Its private fields bind the exact original
document and existing source/attack keys to that state's pre-lane voice relation.

the complete set of current physical occurrences for every participating source

an unrelated companion or a component spanning unsupported staff/measure/voice
contexts remains ineligible. A fragment identifier is never reconstructed from
pitch or geometry. Original byte offsets order already authenticated members;
they never mint identity.
