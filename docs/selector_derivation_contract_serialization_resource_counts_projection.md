## Pure observation implementation

The new counters implement the accepted diagnostic reporting-gap definition only. They do not establish membership in a musical beam defect class and do not change the existing audit verdict or release behavior. Missing parsing stays unavailable. Staff is not a beam partition key; rests do not close chains. No inferred minimal channel number or sounding-overlap policy is introduced. Existing counter units and unsupported cross-scope semantics are made explicit in the report and documentation. Synthetic tests check renaming, independent duplication, cross-staff and rest-bridged chains, and orphan markers. Final persisted Master/Render bytes remain the only inputs.
