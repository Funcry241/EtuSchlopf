The import can infer a written timeline for an otherwise unsupported
performance recording. The inference requires corresponding evidence from the
audio and binds all events to their original MIDI ordinals. The notated meter
enters through the existing seed. The importer has no beam or rest writer.
Explicit notation maps and already supported direct MIDI imports retain priority.

The existing meter-bound owners use the written time signature, including when
the signature is inherited. For compound meter, notation can keep a complete
value inside its ternary main pulse and can show a co-release followed by an
exactly representable rest. Each decision uses the local lane or the bound
simultaneous cohort.
