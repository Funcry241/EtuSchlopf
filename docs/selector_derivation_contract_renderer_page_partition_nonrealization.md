## Derivation and domain

An internally admissible layout is a proposed representation. Its author does
not own the consumer's actual engraving geometry. A consumer can introduce,
remove or displace a page boundary while processing that representation. A
positive process exit alone proves neither page-boundary preservation nor full
musical material preservation. Comparing the bound submitted partition with a
complete independently observed output partition exposes this mismatch without
using a known piece, boundary address or desired repair result as a predicate.

The definition concerns page realization, not the cause of every geometric
mismatch. System changes may coexist. A later implementation may restrict its
repair to a separately justified safety scope, for example a page insertion
whose submitted system partition is otherwise preserved. Such a restriction is
not part of class membership and must not be refined to isolate a known witness.

Missing source binding, an unconfirmed rendering environment, failed conversion,
missing pages or unsupported readback leave the relevant fact unknown. They do
not authorize a new break, fallback source, musical edit or successful verdict.
The class does not diagnose memory corruption and does not cover a broken
occurrence/receipt transport merely because it happened in the same run.

## Necessary distinctions

1. The complete source and materialized plan binding identifies what was tested.
   Observing an unrelated PDF is not evidence about this proposal.
2. The existing upstream admissible domain distinguishes a consumer feasibility
   counterexample from a proposal already disallowed by the planner.
3. Complete supported readback establishes the consumer page partition. A process
   exit, page count alone or a guessed missing boundary is insufficient.
4. Partition inequality expresses nonrealization without choosing which layout
   should replace it. Neither an inserted nor a collapsed boundary grants a
   corresponding productive write.

Renaming source metadata, measure labels or unrelated technical voice labels,
without changing the bound rendered representation, preserves membership.
Relocating an independently bound example changes its observation coordinates,
not the inequality. Independent documents and their probes are independent;
adding another document cannot change the first document's result. Different
pages within one document are not presumed independent: a page displacement
can propagate through all following pages.

## Authority boundary for later implementation

This definition changes no Rust, decision, writer, renderer command, channel
allocation, source/attack identity, receipt, SSC, adoption, release gate, width
model, vertical-capacity model, page-count frontier or preference ordering.

A later repair must reference this definition unchanged from an accepted parent.
The existing layout owner must own every new proposal, and the renderer remains
a feasibility veto. Output boundaries may inform a bound negative observation;
they are not instructions to copy consumer layout into the product.

A sound exclusion must retain the scope of its actual evidence. A failed complete
plan proves failure of that submitted complete plan under its bound source and
environment. It does not, by itself, prove that every alternative system partition
covering the same measure range fails. Generalizing such evidence into a range,
a new vertical limit or a source-independent permanent prohibition requires an
independent contract and proof. No new calibration follows from this definition.

Exclusions must remain run-local, source-bound and environment-bound; unsupported
or repeated evidence must fail closed. Every replacement must remain inside the
originally authorized frontier and capacity/shape domain and receive fresh
consumer confirmation before productive adoption. Existing immutable-source,
materialization-receipt, exact-plan, temporal and musical conservation checks
remain independent and mandatory. Unsatisfiability is an honest failure; it does
not authorize force, an unconfirmed plan, a frontier expansion or note removal.

Normative tests must use synthetic partitions and consumer observations. They
must prove bindings, refusal on unknown evidence, no repetition, unchanged
positive neighbors, independence across documents and preservation of existing
preference and capacity owners. Real music and physical boundary addresses stay
in separate evaluation evidence.
