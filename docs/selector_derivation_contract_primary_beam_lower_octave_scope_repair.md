The parent class definition is byte-unchanged from accepted r1506. This repair
changes only the existing primary-beam interior guard. It first isolates the actual
part containing the query and then uses the same lower octave start/stop observer
as the unchanged anchor scanner. Only origins in the query's scope are admitted. A later boundary does not
retroactively erase a proven interior before it. Unclosed prefixes at a future
boundary are a separate unresolved state: they block new insertions in the solver
and normalizer, but are not asserted as proven interiors that force current clef
removal. Existing surface choices and independent tie checks remain in force.
No general time-gap policy, beam recovery, tie/chord rewrite, changed costs or new
writer authority is introduced. Missing begins stay missing; existing Unknown
handling and independent tie checks remain authoritative. A fresh same-scope group
continues to protect its interior. Upper-only octave directions are not lower cuts.

The existing planner, normalization, E024 materializer, journal, receipt/adoption
and committed reentry remain in force. Musical effect is declared: the existing
cost solver can retain or insert different lower clefs where the prior guard used
a stale old-scope relation, or preserve old-scope prefix protection conservatively.
Only authorized pure-clef edits of the existing course may result. Notes, sounding
content, rhythms, ties, beam tags and octave directions are not edited by this fix.
Actual corpus distribution is measurement only, never a selection whitelist.
