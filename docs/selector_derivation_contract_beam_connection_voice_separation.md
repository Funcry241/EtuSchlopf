## Class and necessary features

The error is incompatibility between a written primary connection and a later
serialization-lane assignment. The predictive form concerns an actual connection
proposal and an already available sealed assignment to the same occurrences.
A merely adjacent note is not a member. Chord members are attached resources,
not independent beam steps. Physical lane compatibility must use the existing
serialization/importer semantics, including legitimate cross-staff connections;
a change of staff alone is not proof of this error.

Both a connection and a separating assignment are necessary. The class does not
make every voice change erroneous, does not require preserving every observed
beam, and does not create an obligation to extend an original group. A complete
ordinary beam edit may legitimately remove a connection; this class never grants
permission to recreate that removed connection from remembered provenance.

The connection and assignment must be bound to the same actual occurrences and
appropriate pre/post states. Source identities come from existing authentic
producer custody. Coordinates and hashes may locate and guard that custody;
they may neither mint identity nor substitute for a missing occurrence binding.

## Two causal observation points, not two score-specific classes

A connection owner may detect incompatibility with the sealed assignment it
already receives. That assignment is not assumed to predict all later repairs.
A later assignment owner may detect that its actual simultaneous edit batch
separates a currently valid connection, including a previously authored extension.
The whole interacting conflict component matters: rejecting one move can leave
another original connection split. Independent components remain independent.

## Repair remains separate

Withholding a proposed connection, transporting a writer-authored extension into
a simultaneous lane move, or another correction requires its own implementation
contract and explicit effect declaration. This definition selects no repair,
allocator, target lane, ranking or renderer interpretation. Original membership
must not be rewritten to describe later extensions as original members.

## Prior evidence and independent evaluation

Existing corpus observations motivated investigation, not the normative feature
list or its numerical scope. No classifier implementing this definition has yet
measured its distribution. Existing two-location diagnostic results are neither
a membership oracle nor an expected cardinality embedded in a future selector.
Synthetic cases must vary names, position, spelling, voice labels, ordering and
independent duplication, and include chords, conflicting batches, cross-staff
semantics, withdrawn connections and unavailable or stale custody.

This take changes no productive code. A future implementation must consume this
contract byte-unchanged from an accepted parent and supply the required repair
scope and multiplicity-invariance contract before any productive write.
