This RefactorOnly cut attaches the prepared pure Rust graph predicate at the
existing append_written_only_probe observation of the actual frozen assignment.
It appends evidence before the existing written-only counterfactual and leaves
that counterfactual, every allocator input and the actual candidate unchanged.
No new writer caller, candidate choice, mutation or admission is introduced.

The existing canonical written projector already captures source/attack/fragment
binding and actual emitted fragment ordinals. Its ordinal is now retained in
the private written occurrence. Graph identities carry these exact values;
positions only locate already identified emissions and their positively bound
projected chord heads. No identity is reconstructed from text, pitch, timing,
voice labels or proximity. Exact source-fragment coverage and unique emitted
identities are checked. Unsupported source/part/host binding stays Unknown.

The graph reuses the actual WrittenInterval type, including its structural
time-block coordinate. Equality of structural blocks prevents overlap between
different written periods; there is no measure-specific decision or target
selector. Only positive written pitched occurrences enter this graph. Grace
occurrences remain explicitly counted as not checked. A hard relation or beam
member outside supported coverage is not silently dropped into a successful
retention result.

The hard_received_bindings graph contains actual positive projected chord
containers, canonical HARD SAME edges and continuation of the same received
source/attack through its actual written emissions. It derives written overlap
separations for different containers and checks the actual serialized production
labels. Technical roles and sounding intervals are not graph inputs. The
four-label-per-staff check is a graph resource check; it does not replace the
existing whole-part importer admission already executed at this call site.

The conditional_received_beam_retention graph adds positive original owner
membership from ActualSourceBeamBindingObservation, bound to the exact original
document and canonical locators. It does not use current XML beam tags, voice
groups, eligible writer components or alignment-filtered subsets as the source
of this membership. No missing owner capture becomes an empty satisfied graph.
These extra equalities are explicitly conditional: group membership alone does
not establish complete ordered marker validity, mandatory retention of every
optional bridge, or the current withdrawal lifecycle. A conditional split or
contradiction is therefore not an unconditional product defect or repair permit.

The pure predicate computes equality closure and checks a supplied assignment.
For a separation inside one class it returns a shortest equality path for that
endpoint pair, plus the conflicting separation. A separate replay verifies the
facts and path without trusting the union-find result. It shares fact derivation
and model validation, not independent producer authentication. The predicate
does not solve coloring and does not claim global minimal unsatisfiable cores.

GraphSatisfied always reports the pending original-notation-voice, silence,
ordered-beam, optional-lifecycle, grace, materialization, import and visible-
preservation proofs. model_complete=false and admission=none remain explicit.
Unknown, violations and contradictions only write diagnostics. The first
witness per graph is an explanation, not a count of all musical defects.
Human locations are emitted only after this read-only result boundary and
never feed a candidate selector or writer.

Synthetic tests cover written contact/overlap and structural time translation,
positive short chord members, forged transitive certificates, resource scope,
actual producer ordinals and independent copies. Real original beam-owner
fixtures exercise the adapter, absent capture, mismatched assignment and
duplicate emissions. The existing real tied-anchor projection test verifies
that both actual producer ordinals survive the written binding.

Acceptance requires ordinary parent admission, build, tests and blocking
Clippy, plus native full-corpus Master/Render byte equality to accepted r1624.
The new graph evidence must be reviewed with its explicit scope and open
premises. No graph outcome claims that the original beam defect is corrected.
