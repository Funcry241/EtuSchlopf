The existing Render spelling owner may apply a note-only journal while
key-selection is inactive. Key declarations stay byte-exact. Initial
coverage is one traditional part-wide signature from the beginning of
the part. A neutral placeholder, multiple key declarations or a local
signature scope is outside this repair. The existing key selection and
Master export remain separate owners.

A retained pitched occurrence keeps its sounding value and existing
rhythmic, structural and display obligations. A source-bound tied
attack is a complete local repair unit. Conflicting same-key chord
spellings are checked before emission. A missing original tied course
leaves that component as received. Chromatic spelling outside the
diatonic set requires a separate decision.
