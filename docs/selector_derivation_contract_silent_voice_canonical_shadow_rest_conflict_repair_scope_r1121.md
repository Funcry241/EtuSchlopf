## Repair-scope derivation

The accepted r1120 parent froze `silent_voice_materialization_conflicts_with_canonical_shadow_rest_role` before selector-sensitive repair code. r1121 consumes that contract unchanged.

The repair does not add an overlap classifier to SilentVoice. It reuses the exact already-bound canonical FinalVisibleRestRole predicate. Each planned visible-rest materialization is probed independently through the existing structural materialization authority. If that concrete result would introduce a new canonical shadow-bookkeeping rest under the same frozen voice plan, that replacement is withheld. Other replacements remain under the existing SilentVoice plan.

The committed FinalPdfSource shadow-rest veto remains unchanged and fail-closed.

## Multiplicity and mixed-candidate boundary

Independent duplication cannot create write authority. A conflicting candidate remains withheld when duplicated.

Mixed plans are not globally rejected. If some replacements are non-conflicting, they may proceed. Residual unmaterialized SilentVoice candidates are accepted as intentional only when every residual replacement is independently proven to recreate the canonical shadow-rest contradiction. Unknown or unreadable conflict evidence is fail-closed for the individual materialization.

## Scope limit

r1121 does not disable SilentVoice coverage, does not change the canonical rest-role predicate, does not weaken FinalPdfSource readback, and does not infer musical identity from raw voice/staff labels. It changes only write eligibility for concrete SilentVoice rest materializations that positively contradict the accepted r1120 error class.
