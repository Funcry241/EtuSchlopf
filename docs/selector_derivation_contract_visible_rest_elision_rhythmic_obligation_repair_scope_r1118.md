## Repair-scope derivation

The accepted r1117 parent froze `visible_rest_elision_without_bound_rhythmic_dispensability_proof` before selector-sensitive repair code. r1118 consumes that contract unchanged and narrows the first productive repair to one existing RestOnly decision: a visible rest in a full rest-only serialization segment is no longer converted to cursor-only time merely because the same staff contains visible pitched activity elsewhere in the measure.

The existing staff-activity observation remains diagnostic through `auxiliary_lane_candidates_seen`, but it no longer grants `auxiliary_lane_attempted` or a replacement write. The old local action-budget/overlap reservation is preserved so suppressing this write cannot unlock a later unrelated RestOnly mutation in the same bounded scan. No new cross-staff proof, semantic-voice planner, ledger, writer, threshold, ranking, or corpus-conditioned selector is introduced.

The product-path readback of the conservative Keep exposed an existing owner interaction: a later canonical role owner can positively prove that a preserved carrier is technical shadow bookkeeping, purge it, and encode the resulting cursor motion with voice/staff labels. Those labels are not a musical obligation of the retired C2 carrier, but they are sufficient for the later SilentVoice coverage planner to reconstruct the technical lane as visible rests. r1118 therefore keeps the existing canonical purge selection unchanged while making its already-authorized C2 materialization identity-neutral. This is the positive technical-role branch already allowed by the r1117 error-class contract; it is not a new proof architecture.

The neighboring complete-silent-lane branch remains unchanged: when the staff has no visible pitched activity and the existing cross-staff exclusion is not triggered, the existing canonical measure-rest transaction may still proceed through the same structural write authority.

## Multiplicity and regression boundary

The changed RestOnly decision is local to each rest-only segment and is conservative preservation. Independent duplication therefore may increase observation counts but cannot create write authority or change another segment's `Keep` result. The existing writer-reaching regression function is extended in place to cover a singleton 4/4 case, a proportional 3/4 case with different divisions and voice label, bounded-action parity, and independent duplicated measures.

The pre-existing canonical shadow-rest classifier regression remains unchanged. No new writer-reaching test call is introduced outside `StructuralWriteAuthority`; the representation-only C2 correction is instead required to survive the real product execution and final persisted readback. Once the existing owner has positively selected a technical auxiliary shadow rest, its replacement is plain cursor time with no voice/staff identity capable of recreating the retired technical lane. The selector itself, overlap predicate, and positive/negative candidate boundary remain unchanged.

## Scope limit

r1118 does not claim to secure every productive rest-elision path. It enforces the r1117 invariant only at the confirmed RestOnly branch and preserves the already-existing positive C2 decision of the canonical FinalVisibleRestRole owner. Similar visible PDF symptoms whose first loss occurs elsewhere remain separate investigation targets. Hidden rests and arbitrary forwards are not promoted to visible notation by this repair.
