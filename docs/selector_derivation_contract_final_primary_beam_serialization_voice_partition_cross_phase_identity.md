## Measurement-only implementation

This contract governs only the r1047 diagnostic classifier required to explain the already frozen error-class evidence gap. It does not change the parent error-class definition, produce a repair scope, authorize a writer, alter beam encoding, or mutate MusicXML.

Each Cross-Voice observation is classified independently. Adding another independent observation cannot change the classification of an existing observation. Any later productive write remains subject to a separate take and a fresh candidate-duplication proof.
