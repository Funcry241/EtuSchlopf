## Scope and owner

The unchanged Stage-A definition is consumed from natively accepted r1528.
The canonical StructuralWriteAuthority gains a narrowly source-bound product
realization at the existing final Render closure boundary. This is an artifact
representation of the final selected Master only when Render history is absent;
it is not a new Genesis, reset, transformation, receipt or source selection.
Existing Render history follows the unchanged strict closure and cannot fall
back to Master when its artifact is missing or wrong. The output must be the
SourcePlan Render path bound at Render construction. Master and target are
canonically distinct, Master bytes must equal the sovereign released Master,
and create_new refuses every existing target. Readback witnesses both exact
source and product bytes before lineage closure. No optional PDF is invented.

The Render closure now distinguishes the explicit absence of transformation
history from the existence of an unchanged required product representation.
The original close_render_sovereignty still strictly witnesses state versus
artifact, including absence, in its existing callers and regression tests.
No music gate, recovery owner, musical writer, receipt or frozen origin changes.

Existing transformed output is read-only here. The new product sink has one
productive caller, the final release boundary after source selection, final
Master adoption/layout and renderer execution, before report publication.
Product I/O or binding failure returns an error and prevents an OK report.
No arbitrary XML is accepted: bytes come only from MasterAdoptedState.

This new artifact authority and the absence-history closure distinction need
adversarial review before the native take. Native acceptance remains pending.
