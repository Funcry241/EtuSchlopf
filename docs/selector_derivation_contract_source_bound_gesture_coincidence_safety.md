## Parent and scope

MusicMutation on natively accepted r1561. Its error-class definition stays
byte-identical. The existing Gauss A7 predicate and its Gauss-only reach remain
unchanged. The new point rule is additional, not an interval replacement.
No general cross-channel overlap rule, raw-overlap exception, source-unison
freeze, scoring constant, tie-break order or search-budget change is introduced.

The four paths are GaussCandidate, GaussChain, BrokenGesture and ConstrainedTail.
Each binds its own actual phase seed. Explicit XML divisions must agree with the existing 96-quarter notation axis; another or malformed division value grants no new move. One supported physical piano part is the
keyboard domain, not separate staff or technical voice labels. All proposed
anchors remain in the source measure under the original selectors; the bound
measure/local-time partition therefore represents the supported absolute-time
relation without comparing unrelated source/notation grids.

Complete observed fragment fields are compared with a fresh atomic parse before
carried source/attack IDs are used. Regular and continued pitched fragments must
reference an existing carried attack with that source. Missing IDs do not prove
continuation. Canonical raw pairs come from the already bound source-plan rows,
never from physical coordinate matching. Byte spans locate existing carried
occurrences and proposed anchors only; they do not create semantic identities.

## Proposal and unchanged writer

The source candidate and anchor slot must bind to their exact atomic note spans,
measure, onset, pitch and presentation fields. An independent source note is
required by the existing gesture safety predicate. The proposed duration is
slot.duration.max(1), which is the duration the existing chord serializer writes;
it is not silently replaced by the atomic member's duration. Overflow or a
cursor-derived mismatch grants no new proposal.

The generic point kernel uses the existing source and attack ID types. It
compares every relevant other attack. Equal raw pairs are allowed by R6, subject
to all existing other protections. Unknown roles or relevant identity/placement
facts provide no permission. Staff and voice do not split the point relation.

Each scored or executed attempt clones the same seed occupancy. Both use the
same admissibility and confirmed-move progression. A successful selected move
updates the R6 point view and the physical A7 interval view together before any
new edit is prepared. A rejected move updates neither view. No-target handling
leaves the source at its current phase-seed position without removal, cloning,
restification or identity minting.

The original anchor functions still apply their existing distance, half-cell,
mode, score and byte-order tie policies over admitted slots. A7 is still called
only for Gauss. Existing Gauss scoring adds 9,000,000 when no anchor is available;
execution still skips that source without adding a penalty. This historical
residual difference is retained and is not described as complete score/execution
identity. Tail history pressure, used-slot penalties and frontier sizes stay as
before. New occupancy can legitimately change the examined front and winner;
the native difference matrix must cover every affected etude, not just witnesses.

## Tests and authority limits

Synthetic kernel tests cover source unisons, different raw keys and onsets,
reservations, freed origins, rejected speculative swaps, unknown identity/role,
independent alternatives and relabeling. A finite independent whole-state test
checks the global pair relation after sequential moves, including raw unisons.
New adapter tests read only synthetic fixtures: complete-field mismatches,
missing IDs, cross-channel collision, free alternatives and written slot-duration
simulation. They invoke no musical writer. Existing legacy writer tests retain
their prior assertions and only receive an explicit synthetic occupancy argument.

No proof, source identity, receipt, adoption, XML writer, release gate or R6
report is changed by this repair contract. Full native ten-piece execution,
source/attack conservation, no newly introduced coincidence, complete R6 pair
lists, R1-R5 nonregression and complete changed-measure/page image review remain
acceptance obligations, not results claimed by this document.
