## Scope

A page can end naturally with unused space. Its bottom remainder alone does
not establish a defect. The class applies when the minimum-system preference
excludes a fresh alternative that improves the distribution of bottom
remainders on non-title pages without moving a comparable remainder elsewhere.
A title and its reserved vertical space are accounted for separately. Bottom
remainder is measured from the last system to the usable bottom boundary
under the same paper, margins and scale.

A later implementation should begin with one additional system at fixed page
count. It must keep contiguous measure order, stay within the existing
horizontal capacity and page shape constraints, and avoid introducing
single-measure systems. Independently bound phrase, page-turn and notation
obligations remain binding. No threshold or particular page assignment
follows from this definition. A larger system count alone is no evidence
of an improvement.

## Authority and evidence

The joint page and system planner remains the decision owner and its existing
materializer remains the writer. A complete fresh rendering must confirm
every submitted system and page boundary. Compare the source-bound physical
extent of every affected page, including horizontal occupancy, adjacent
system clearance, clipping and bottom remainder. Verify musical content
outside the layout projection against the same source. An unknown result
preserves the confirmed incumbent. Renderer success alone grants no write
authority. Each document has an independent search. Competing partitions
of one document are alternatives for that document only.

This definition adds no planner behavior, renderer command or writer.
The existing fixed-ordered-system balance and fewer-page classes remain
separate. This class must exist unchanged in an accepted parent before a
selector-sensitive implementation can use it. Any trial outside the current
shape, width, or page-count domain requires its own authority.
