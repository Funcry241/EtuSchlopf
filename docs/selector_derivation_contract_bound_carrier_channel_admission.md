## Bound physical carrier preservation

Every emitted pitched carrier remains bound through the complete original producer
receipt. A chord syntax carrier still requires an actual parsed physical anchor.
A pitched anchor requires its own exact receipt key. A non-pitched anchor instead
retains its exact physical measure/note position in the already bound projection;
that locator is an equality check, never a musical identity or permission. Its
non-pitched bytes, ordered positions, roles and resource protections remain under
all existing guards. It supplies no beam state, group, owner or inherited edge.
Missing physical anchors and missing pitched anchor receipts still refuse.
No rest, head or member is created, removed, restified, rebound from similarity,
or promoted from Unknown. Every new connection still needs positive original cohorts.

## Finite complete component alternatives

The complete prior whole-channel search remains first. The existing distributed
phase retains its guest, component and host ordering and its first full placement.
If its complete placement is refused, the additional family varies one whole
component's host at a time, retaining the same deterministic construction for
all other components. Every existing host is considered for that component.
This is a finite polynomial candidate construction, not exhaustive Cartesian
search, a threshold, timeout or impossibility proof. HARD SAME classes and
connected measure inputs are never split. The unchanged conflict edges and
lower-primary reader predicate constrain construction; every complete partition
still passes the full non-monotone proof. Each completed evacuation removes a
channel before entering the existing memoized search. An existing successful
whole-channel or deterministic distributed result is returned unchanged. No slot
increase, ranking threshold or new writer is introduced.

The actual full producer projection, exact source/attack/fragment correspondence,
original all-level states, closed written edges, bystanders, cohort permissions,
unknown context, rests/cursors and bound label continuation remain binding.
Native consumer experiments are independent evaluation, never search input.

## Fail-closed productive seal

Allocation diagnostics can still represent a refused or unknown planning result.
Immediately before the existing productive frozen voice plan is installed in
CandidateMaterial, require complete canonical written evidence, the exact bound
source/channel/role plan and a fresh check with its actual bound labels. A missing
model, foreign binding or unreserved required channel returns an error before
that installation. No alternate musical candidate is selected to bypass this
failure. A reported diagnostic verdict alone never admits productive output.

Synthetic controls cover physical non-pitched anchors, existing true pitched
head receipt binding, complete placement alternatives with real cohort and
bystander refusals, and failed/unknown capacity seals, with relocation and the
existing independent duplication controls. Real files remain
external evaluation only. Native preservation and a fresh Windows full corpus
remain required; this scope itself claims no final release or playability.
