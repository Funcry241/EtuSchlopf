The separately accepted repair scope is
`docs/ottava_reader_reminder_repair_scope_v1.md`, unchanged from accepted r1518.
All safety restrictions implement its existing obligations. Source and directive
binding prevents stale evidence; creator origins prevent late identity invention;
compatible noncompeting line scope preserves meaning; exact generated-word
attribution excludes user text. Unsupported font/PDF/staff layouts, absent glyph
metrics, ambiguous local cohorts and missing or stale observations retain the
baseline. The geometry compares real glyph boxes and stroke widths/ordinates;
no new musical gap duration or witness-derived pixel threshold is introduced.

Cohort cardinality is used only to bind an already identified local reading group
to its observed glyphs, never to select a global winner. Independent groups retain
independent decisions. A duplicated origin marker is an ambiguity of that same origin,
not a veto on other independent origins. Ordinary layout restarts retain the
existing projection. A later continuation in a restart bar is not treated as its
first entry merely because of the bar's layout flag.

A pure readback does not issue origins, receipts or musical permissions. The
RegisterNotation domain owns the reader decision; the existing E012 calculation
performs every XML removal. E007 remains byte-identical. Its already-existing
original course companion validates the receipt, and an observation of the opaque
sovereign states closes adoption. The final export guard accepts a missing word
only for that exact adopted post and transported direction ordinal. The final
renderer must retain the observed line/orientation; otherwise release fails closed. r1520 permits vertical engraving translation
only after fresh current-cell evidence; page, horizontal cell bounds, full line
span/width and glyph horizontal bounds remain exact. Missing or locally ambiguous
current evidence still refuses release; no nearest-position ranking or measured
vertical-distance cutoff is used.
