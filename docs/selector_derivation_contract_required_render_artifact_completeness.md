## Boundaries

The error class is a mismatch between a declared required product artifact and
its realization, caused by making realization depend on optional transformation
adoption. It is independent of whether PDF rendering is requested. Classification
must use product obligations, authorized final source provenance and actual
artifact state, never musical witness features.

The frozen source remains sovereign. This definition grants no permission to
copy Master into Render, mint a Render state, change source selection, overwrite
an existing file, add a writer root, bypass receipts or relax MusicXML schema,
serialized time, source-adoption or final product checks. A later repair needs
an independently admitted artifact owner and exact source/destination binding.
The existing recovery owner remains the only recovery owner.

## Neighbors and synthetic evaluation

- A required artifact is absent although no optional transformation was adopted:
  the product obligation remains open; a zero transformation count is no success.
- An artifact is present but stale, mismatched or not from the final authorized
  snapshot: presence alone does not close the obligation.
- An optional artifact was not requested: this class does not invent a new
  obligation. A PDF omitted by explicit request is not a missing required XML.
- A candidate was rejected: the obligation does not authorize using its bytes.
- A valid current required artifact already exists: no duplicate writer or
  musical recomputation follows from this definition.

Normative tests must use synthetic authorized snapshots and independent output
paths, covering present/missing/stale artifacts and requested/optional outputs.
Renaming inputs, moving directories, changing the music or adding independent
projects cannot change the product obligation or create write authority.

## Exploratory evidence and acceptance

A synthetic full engine probe reached an OK report with zero blockers after the
report vocabulary and explicit no-PDF outcome corrections, then the unchanged
persisted-byte product gate rejected the absent required render artifact. Source
inspection found that optional adopted Render transformations determine whether
a Render artifact exists. These are exploratory observations known before this
definition, not post-freeze corpus measurements. No runtime repair is included.
The native lifecycle evidence determines acceptance of this definition.
