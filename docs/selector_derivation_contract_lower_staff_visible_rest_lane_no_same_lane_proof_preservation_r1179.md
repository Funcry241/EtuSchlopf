## Derivation

The accepted parent lineage already freezes the causal error class `visible_rest_elision_without_bound_rhythmic_dispensability_proof`. Its positive boundary allows elimination only when the same musical responsibility remains legibly represented, an equivalent redundant visible representation survives, or the carrier is positively established as a technical helper without independent rhythmic obligation.

The existing lower-staff anchor owner has one concrete interval-bound proof: complete same-lane pitched coverage of the affected rest interval. The no-same-lane branch has no such proof. The fact that a technical lane contains no same-lane pitch is not itself a positive semantic classification of the visible rest carrier.

The r1177 corpus measurement shows that the current no-same-lane branch is broadly exercised, but that distribution does not define or narrow this repair. The selector change follows from the prior obligation and would be the same if the corpus contained one, sixteen or zero current examples.

## Multiplicity and authority

The decision is local to one carrier and its bound interval evidence. Duplicating or relocating an independent unproven candidate cannot turn absence of proof into proof.

No writer or StructuralWriteAuthority surface is added. The existing candidate planner, scoring, ordering, action budget, per-scope conflict logic and materializer remain unchanged. This repair only removes eligibility from candidates for which this owner lacks positive bound rhythmic-dispensability evidence.

## Candidate duplication probe

The productive predicate is local to one carrier and accepts no candidate-count, global-ranking or corpus-multiplicity input. The r1179 recovery adds no new direct caller to probe this via the legacy writer graph; invariance is checked structurally by preserving the pre-existing call-site set and by the contract that no multiplicity-sensitive input participates in the decision.
