## Causal definition

This class exists when a productive notation owner can remove an already visible rest carrier without a positive proof, bound to that carrier and its complete interval, that the visible rhythmic information is dispensable in the resulting notation.

The defect is an authority defect at the deletion decision. Preserving sounding events, MusicXML cursor time, parseability, or raw staff/voice labels does not establish that the visible rest is musically redundant.

A visible rest is not a member merely because it could be written differently. The class requires a productive elision proposal without sufficient positive dispensability evidence. Conversely, an elision with independently bound evidence that the same musical responsibility remains legibly represented, that an equivalent redundant carrier survives, or that the removed carrier is positively proven technical with no independent rhythmic obligation is outside this class.

Missing or contradictory dispensability evidence means the eliding owner has no authority to remove that already visible carrier. This `Keep` consequence concerns only preservation of an existing visible representation; it does not authorize revealing hidden rests, converting arbitrary forwards into rests, completing every staff to a full measure, or constructing a new voice architecture.

## Necessity review

1. A concrete visible rest carrier is necessary because the class concerns loss of already visible rhythmic information, not creation of missing notation.
2. A productive elision proposal is necessary because a merely hidden pre-existing carrier is a different problem class.
3. Binding to the complete affected interval is necessary because activity elsewhere on a staff, voice, or measure cannot prove that this interval is rhythmically represented.
4. Positive dispensability evidence is necessary because technical section shape, labels, sounding equivalence, and cursor invariants describe representation mechanics rather than the musical obligation of the visible rest.
5. Explicitly allowing proven continuation, redundancy, and technical-carrier cases is necessary so that the class does not turn conservative preservation into a blanket ban on legitimate rest elision.

## Evidence requirements for later repair scope

A later repair-scope take may restrict an existing productive rest-elision owner so that absence of the required proof yields preservation. It must reference this contract unchanged from an accepted parent.

The later repair scope may be narrower than this error class when the narrowing follows independently from existing owner authority, available evidence, materialization safety, or preservation invariants. It may not use project identity, measure identity, witness-shaped context, corpus uniqueness, or a scorewide single-candidate rule.

No later repair is required to construct new cross-staff or semantic-voice proof merely to retain a visible rest whose dispensability is unproven. If an existing branch continues to perform positive B/C elisions, only those remaining deletions require the evidence actually needed for their authorization.

Normative tests derived later must be synthetic and corpus-independent. Renaming, relocation, irrelevant musical perturbation, and independent duplication must not change the local decision.
