## Causal definition

A stateful renderer can consume a beam start and end before consuming a rest
whose musical onset lies between them. In a later cursor traversal that rest
arrives after the renderer has closed the connection. Its earlier musical
onset does not retroactively reopen the renderer's connection state. Correct
endpoint tags and timed events can thus coexist with lost required continuity.

This differs from a connection not yet evaluated before canonical projection,
from endpoints assigned to different final technical lanes, and from a
rhythmically contiguous pitched cohort split by cursor traversal. Here an
actual authored connection already exists, an existing rest participates in
its interval, and consumer rest processing is the causal boundary.

Actual adoption, actual pitched/rest occurrence binding, the applicable final
lane relation and renderer consumption behavior are required evidence. Tags
alone prove neither authority nor fragmentation. A counterfactual render proves
an encoding dependency, never permission to alter musical responsibility.

## Necessity review

An adopted connection avoids inventing a musical preference. An intervening
represented rest distinguishes ordinary pitched-cohort stitching. Consumption
outside the active connection establishes causation rather than unusual XML
order alone. Preserved timeline, responsibility, lane relation and authored
states distinguish encoding correction from musical rewrite. Restored consumer
continuity is necessary because changed bytes alone do not resolve the defect.
None of these requirements depends on a particular score or location.
