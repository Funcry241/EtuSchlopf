## Identity and decision course

The actual creator assigns nonprinting XML comment markers inside the existing
start, continue and stop directions. Markers carry creation provenance and are not selectors
on musical coordinates. The existing exact register-materialization check also
checks these markers before marking the born course validated. Known markers
survive ordinary XML copying; missing, duplicated or inconsistent markers are UNKNOWN.

The current renderer-feasibility probe supplies a PDF observation of its exact
source, not a report or old PDF. RegisterNotation receives immutable observations
bound to that source and the selected layout directives. The pure observer supports
one-part piano staff cells and the existing MuseScore/Qt PDF profile, real Leland
embedded glyph bounds, supported SMuFL octave glyphs, horizontal line geometry,
its preceding orientation indication and an unambiguous local cue cohort. Unknown
format/metrics/attachment leaves the baseline. Other independent groups do not
select or veto the group under examination.

The domain makes the accepted reader decision for the actual selected pre-layout
source. E012 applies the bounded removal ranges inside its existing per-measure
calculation. It removes only exact generated continuation word wrappers plus the
private, nonprinting creation markers. Therefore public XML differences against the
parent are confined to supported generated words; internal provenance comments
are absent again at the final artifact. Notes/rests, line identities, octave scope,
placements, attacks, durations, beams, ties, slurs and clefs retain their owners.
