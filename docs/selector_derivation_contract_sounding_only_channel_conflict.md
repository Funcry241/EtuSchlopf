## Boundary and necessity review

This Stage A defines an independently measurable reason for exclusion, not a claim that sounding overlap is always irrelevant. Written occupancy, chord/tie/source-role relations, consumer import safety and sounding preservation are independent requirements. A later read-only census must distinguish sounding-only edges, written overlap and role constraints before any allocator rule can change. A candidate fitting fewer technical channels is not by itself evidence of correctness. Existing synthetic sounding-overlap tests remain unchanged; they require a separate fachliche review. No conflict edge, allocator, role, threshold, search, test expectation or writer behavior changes in this take.
