## Separate class and correction scope

The accepted r1323 class remains byte-identical. This implementation adds a local
negative compatibility constraint to existing channel allocation. It neither
promotes an audit result to authority nor selects a historical location. Existing
canonical roles and HARD SAME classes determine the admissible correction scope.
Contradictory written obligations inside HARD SAME are rejected, never split.
Different staffs do not remove a written conflict; no opposite-hand fallback is
introduced. Endpoint adjacency remains compatible. Equal intervals alone remain
insufficient chord proof.

The sole FinalChord projector supplies output bytes and exact provenance inside
its existing StructuralWriteAuthority planning owner. Its existing read-only
probe wrapper explicitly discards unadopted exact receipts. The canonical plan
carries immutable occurrences and the complete projected XML. The existing freeze
boundary requires exact byte equality before channel construction. No audit-only
rows, geometry search for occurrence identity, ambient cache, external new writer
caller, or new byte projector is used. Missing rows, unknown endpoints, nonpositive
intervals and unbound provenance fail closed. The initial projection represents
all original canonical pitched fragments; this stage grants no omission authority.
Later certified render omissions retain their existing owner and witnesses.

## Multiplicity and labeling

The added eligibility decision examines one pair in its explicit local interval
conflict domain and all members of an offered channel. It has no scorewide quota,
rarity threshold, winner election or highest-ranked repair candidate. Existing
structural allocation order names channels; a temporal-obligation tie-break replaces opaque
ID ordering where class descriptions differ. Pitch and register do not enter that
allocation tie-break. Written membership uses interval and
positive chord evidence, not that tie-break or legacy label preferences.

Owner-local synthetic tests duplicate disjoint independent obligations one, two
and five times and compare the existing local channel decisions. These probes
must pass in the native strict test stage before productive corpus writes. Other
probes cover missing evidence, endpoint adjacency, both staff presentations,
legal/contradictory HARD SAME cohorts, a channel with a compatible offering member
and an incompatible other member, and opaque-ID/input-order renaming.

The label binder first designates the first sealed channel for each canonical
role preference in the existing role/channel order, then reserves its label.
UpperPrimary and LowerPrimary retain 1 and 2 when present. UpperSecondary wins the
shared 3 preference over UpperAuxiliary; LowerSecondary wins shared 4 over
LowerAuxiliary, by existing role precedence. Supplemental channels use available
legacy labels or the smallest free label excluding all other reserved owners.
These cosmetic names never determine roles. Adding an upper supplemental channel
cannot consume the lower main label. No fixed reservation of six role numbers is
used; absent roles reserve nothing.

## Semantic continuity and validation boundary

The channel fingerprint includes normalized class sounding/written descriptions,
exact-cohort semantic descriptions, all three conflict relations and the actual
channel partition. Semantic table indices compress relation rows; opaque source
IDs, byte offsets, channel names and numeric XML labels do not enter it. Existing
consumers only transport this private channel fingerprint into the serialized
voice plan and label-alpha variants. The separately used canonical structural
fingerprint and output receipt binding remain unchanged.

Twelve new tests are owned physically by StructuralWriteAuthority. An end-to-end
synthetic binding/projection probe compares pitch, written onset/duration, staff,
chord syntax and ties before/after label separation. Existing beam/rest consumers,
SSC envelopes and exact receipt authority remain unchanged; their native tests
and actual corpus output still have to validate the downstream behavior.

Local native validation results are recorded in the r1324 report. Packaging does
not establish Windows corpus convergence or unforced MuseScore import. Runtime acceptance must measure
actual Master/Render collisions and musical invariants independently. A PDF
produced with -f does not establish unforced renderer acceptance.

## Chord proof and occurrence provenance

A rest-anchored or orphan chord member retained unchanged by the existing owner
can have complete positive-interval provenance. Its exact physical host remains
bound, while its pitched-anchor witness is explicitly false. It is not omitted
and cannot obtain legal synchronous-chord authorization by common class or equal
geometry. Existing rejected-encoding preservation assertions remain unchanged.

## Exact positive head extent

Each immutable occurrence now carries its actual projected physical head's onset
and checked end in addition to its exact byte anchor. Sharing requires canonical
HARD SAME, the same positively pitched nonmember head, common head bounds, each
member's onset equal to that head's onset, and each positive member ending no later
than that head. Equal member duration is not required. The longest observed member
is never substituted for the actual head. Rest/orphan hosts retain provenance but
cannot authorize sharing. Head intervals enter normalized semantic evidence;
byte offsets and opaque IDs remain excluded. Rejection diagnostics expose the
pair's actual written/head intervals and continuity IDs without changing decisions.

Production-path synthetic probes cover unequal and equal members, varied units,
member ordering and both staff presentations. Independent counterfactuals remove
canonical edges, pitched authority or exact head identity and change member onset,
member extent or head bounds. None may acquire chord authorization from geometry
alone. The accepted error-class definition is byte-identical to r1323.
