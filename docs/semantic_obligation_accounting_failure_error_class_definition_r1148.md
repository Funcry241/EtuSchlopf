## Purpose

r1148 performs only the `causal_class_first_v1` foundation step for a structural defect class above individual rest-elision decisions. It freezes the class before any observation, accounting, classification or gate code exists.

The frozen contract is:

`docs/selector_derivation_contract_semantic_obligation_accounting_failure.md`

This take does not change MusicXML, Render-MusicXML, PDF output, productive rest selection, writer reachability, thresholds, scoring, corpus targeting, gates or release behavior.

## Frozen causal error class

The class is named `semantic_obligation_accounting_failure`.

A member requires an obligation that a versioned semantic contract derives from the authoritative origin epoch, at least one transformation up to the final persisted epoch, and at least one cell of the obligation domain that is neither continued through certified identity-bound correspondence to a contract-conformant fulfilment nor terminally discharged by contract-admitted evidence under the obligation's own lineage.

The class is norm-neutral. It does not decide whether a visible rest is itself an obligation or only one admissible realization of a higher rhythmic obligation. That normative decision belongs to a later, separate contract take.

## Why a second class next to r1117

The r1117 class `visible_rest_elision_without_bound_rhythmic_dispensability_proof` locates the defect at one productive elision decision. Guarding such decisions one path at a time leaves the composition of transformations unaccounted: several locally authorized steps can still lose an obligation, for instance when correspondence is lost before a later step sees an apparently empty lane.

The new class locates the defect where it structurally arises: the product has no conserved object on which the survival or legitimate release of a semantic obligation must be accounted across representation changes. r1117 stays valid and unchanged.

## Separated diagnostic states

Accounting failure, semantic violation and existing gate escape are distinct. Only the first defines membership. Semantic violation is decidable only through carried identity and otherwise remains unknown; gate escape is an observed property of the current gate inventory and never part of the cause.

## Explicit exclusions

The class is not defined by Etude identity, measure number, page/system position, meter, divisions, tick values, durations, staff number, numeric voice label, pitch/register pattern, the owner or path that altered the representation, acceptance by existing projection gates, or rarity/uniqueness in the current corpus.

The current corpus is evaluation evidence only. No real Etude fragment is made normative by this take.

## No measurement, no authority

`CorpusDistributionPurpose` is `not_yet_measured`. Without certified correspondence relations every contract-derived obligation would currently be unaccounted, so the class is not measurable on the current product state; measurement becomes meaningful only for a frozen concrete semantic contract.

r1148 adds no reader, ledger, classifier, selector, repair scope, MusicMutation, writer, threshold, weighting, gate or productive data path.
