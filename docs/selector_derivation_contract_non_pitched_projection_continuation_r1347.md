## Prerequisite boundary

This cut implements only the production-coverage prerequisite of the unchanged
accepted capacity class. It neither classifies a part as capacity-infeasible nor
allocates, reuses or rewrites channels. Exact spans locate the actual owner input
and its actual output; they do not infer source identity through musical tuples.
Non-pitched role origin remains explicitly unbound. A complete physical mapping
must not be promoted to a complete canonical role mapping or class membership.

All non-pitched inputs to this projector participate, including hidden notes and
physical rest chord hosts. There is no corpus-conditioned narrowing, rarity
filter, preferred measure or global ranking. Independent occurrence duplication
adds an independent row rather than collapsing sources or changing another row's
transport. Uniform time scaling, transported staff labels and arbitrary voice
labels preserve continuation, except that the unchanged upstream musical rest
projection still uses its existing within-input equality relations.

Seven synthetic actual-projector tests verify this boundary. There is no new
repair selector, role inference, writer capability or byte projector. Existing
source role derivation, musical decisions and channel allocation stay unchanged.
