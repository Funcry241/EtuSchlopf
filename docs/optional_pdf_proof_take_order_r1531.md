# N1: Annahmereihenfolge r1531 / r1532

r1531 friert ausschließlich die kausale Fehlerklasse ein. Produktive Rust-
Quellen, Gates, Pins, Tests und Musik bleiben bytegleich zum angenommenen
r1530. N1 ist mit r1531 noch nicht behoben.

Erst nach erfolgreicher nativer Annahme von genau diesem r1531 darf r1532
installiert werden. r1532 enthält die lokal geprüfte E007-Korrektur. Diese
zusätzliche Vorstufe ist vom unveränderten Parent-Zulassungsgate verlangt.
Keine Annahme wird durch lokal grüne Prüfungen ersetzt.

Beide Takes enthalten keine produktive Taktarten-Erweiterung und keinen
Vorschlagsimport. Die bisherige B-Planung bleibt ein separater Arbeitsstrang.
GitHub und öffentliche EXE-Veröffentlichung sind nicht Teil dieser Takes.
