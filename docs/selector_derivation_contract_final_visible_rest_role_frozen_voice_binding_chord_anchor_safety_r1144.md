## Derivation

Accepted r1139 defines the final-role/final-voice ordering error class before this selector-sensitive change. Accepted r1136 independently proves that a rest which physically owns following `<chord/>` members cannot be converted through a forward-bearing rest rewrite without risking pitched occurrence identity. r1144 composes those two already established facts.

The safety feature is local and structural: after parsing the note stream, an eligible rest must not be immediately followed in the same measure by a parsed chord-member note whose physical anchor is therefore that rest. No corpus identity or numeric witness is consulted.

## Authority closure

The r1143 architecture is preserved but rebased directly on accepted r1139: the late stage derives a pure replacement list, delegates in-memory materialization to the existing canonical StructuralWriteAuthority capability, and persists only through the existing FinalNotation checkpoint. No new writer root, checkpoint family, repair authority or release bypass is introduced.

## Multiplicity and relocation

Each candidate is classified from its own bound role, local temporal overlap and local physical chord-anchor dependency. Duplicating an independent candidate cannot change another candidate's anchor relation or eligibility. The normative fixture uses symbolic measure identifier `x` and synthetic voice labels only.
