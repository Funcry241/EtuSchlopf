## Parent, scope and source preservation

The required class document is inherited byte-identically from r1541. Installing
r1541 and obtaining its native acceptance must precede applying this Take. Local
preparation can use its exact known payload without a new export round trip;
it is not a claim that the user's installation has already accepted that parent.
The existing r1541 payload needs no change. This follow-up uses the accepted
r1542 implementation as its immediate parent and preserves the error-class
definition byte-identically.

This follow-up remains inside the accepted redundant-page-retention class.
It is not a global page minimum and not the full Schloepfchen formula. The next
lower admitted count is always the nearest strict page reduction; no desired
numerical page count is introduced. After each fresh confirmation the same
operator may submit its next reduction. The most recently confirmed complete
plan replaces the previous incumbent before that next trial. A rejected trial
stops this chain immediately and retains that latest confirmed incumbent.
The already existing round limit is neither raised nor moved. At its last
round the currently confirmed plan is returned without submitting a new trial. An insufficient inherited
vertical ceiling yields no candidate and no override.

All partitions within the same whole-score layout are one explicit conflict
group. Independent documents share no incumbent, exclusions, ranking or write
budget. The pure builder uses no process or file input. Synthetic independent
calls and complete small fixed-system enumeration verify its locality and the
existing comparator's ownership. No real-score fixture is managed or selected.

## Existing owner and consumer obligations

Only the existing committed-source joint-plan oracle schedules the trial. It
uses the existing promoter, one original materializer, FinalPdfSource preservation
and renderer path. No new writer, reader, file type, renderer command, physical
calibration, source identity or music mutation is introduced. The flat system
course is copied constructively; no PDF matching creates musical identity.
The original page-count preference and horizontal search are not rewritten.

An accepted ordinary plan is an incumbent, not a fallback document. Its source,
renderer and command were confirmed before the trial. Binding is captured then
and checked again before either trial adoption or incumbent retention. A changed
consumer, unknown/missing PDF, unavailable readback, source/plan mismatch or
collapsed boundary still fails through the original checks. A complete supported
insertion only establishes rejection of this optional trial. It does not erase
the already confirmed incumbent under the unchanged binding. Existing ordinary
no-good learning and exact-partition search remain unchanged outside the trial.

The existing register-reader observation stores evidence by immutable source
and layout-directive key. Both confirmed layouts may be observed, but only the
finally selected directive key can supply evidence to the original later owner.
No observation from a rejected trial is registered as confirmed.

note, rest, tie, voice, staff, onset and duration obligations stay with the same
