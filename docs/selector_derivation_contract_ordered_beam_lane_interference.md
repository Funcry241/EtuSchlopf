CausalFeature: a current committed positive beam connection is bound to exact occurrence containers and its complete written interpretation
CausalFeature: a later allocation keeps its endpoints together in a consumer serialization lane while changing the intervening ordered lane input
CausalFeature: interpreting the complete resulting marker sequence loses that connection because the changed lane input replaces, closes or interrupts the open chain
NonCausalContextExcluded: project and measure identity, source identity values, numeric voice labels, exact pitch, duration and member count, staff number, rest-gap presence, corpus frequency, discovery order and visual resemblance

The class follows from the state transitions of the actual written beam reader.
A new opening can replace an open chain, a closing can consume it before later
members, and an interruption can invalidate it. The complete ordered input
determines applicability, including the consumer's chord-container, rest,
cross-staff and supported beam-level semantics.

The positive precondition requires current owner evidence and actual written
readback for the same connection and representation epoch. A historical group
identifier or a shared original cohort alone does not establish that precondition.
An incomplete original group and a closed marker sequence with an unrelated
opening or closing need explicit classification before they supply obligations.

The accepted beam_connection_voice_separation class covers separating endpoints.
This class covers loss while endpoints remain together. Both classes require
exact carried identities and their own pre/post evidence. Coordinate matching
cannot create occurrence identity.

This definition supplements existing connection and extension custody contracts.
A complete, explicitly authorized beam edit may change a protected relation
within its own declared effect. Allocation alone grants no such edit scope.

This Stage A freezes the class before its implementation. Its distribution has
not been measured under this definition. Earlier syntactic pairwise relation
counts do not establish the number of instances of this class.
