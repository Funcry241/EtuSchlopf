## Observation boundary

The counterfactual allocation stays local to the existing diagnostic method.
Production receives the existing allocation. The probe has no adoption, repair,
selection or release authority. The shared canonical projector emits temporary
XML and explicitly discards its unadopted receipts through its existing
ReadOnlyProbe lifecycle. Additional discarded-probe accounting is diagnostic.

Every changed occurrence label is reported. The result document keeps its
existing measure masking. The existing console channel receives the same
human-readable locations for evaluation. Locations never flow back to an
allocator or writer decision.

The readback compares canonical occurrence coverage, non-voice note bytes,
chord attachments, non-pitched carriers and role interpretation, plus lost and
added written beam edges. It reports differences without accepting them.
This stage precedes downstream beam alignment, rendering and PDF export.
Canonical edge preservation alone supplies no final PDF proof. Missing
projection or consumer admission remains explicitly unavailable.

Synthetic tests vary opaque identities and duplicate independent beam groups.
They verify that a label split can lose closed written connections while
retaining every note byte, and that an identical projection loses no edge.
