## Derivation from the accepted parent error class

The unchanged causal parent contract `semantic_obligation_accounting_failure` requires identity to be carried rather than rediscovered. r1188 supplies the opaque edit identity and r1192 binds it to exact complete-document state provenance and final artifact epochs.

The accepted r1192 corpus then exposes a distinct accounting question: many edits are applied in candidate buffers that never become selected states. Treating all such applications as missing final receipts would conflate successful local execution with productive adoption and would pressure the audit to invent lineage for rejected branches.

r1193 therefore adds only the missing process-disposition observation. It consumes the existing identity-safe state ledger at moments where a productive owner has already selected a state. It does not participate in that selection.

## Frozen scope and completeness

The accepted r1192 result projection localizes every final-epoch UNKNOWN Applied edit to ten origin callsites. Source ownership inspection shows their selected consumers are the direct octave/clef materialization paths, the hidden-chord best replacement, the corpus repair best replacements, the editorial-voice best replacement and the final-rest exact-readback acceptance branch.

r1193 instruments those consumer handoffs. The absence of a selected-state observation is interpreted as `NO_SELECTION_WITNESS` only within this frozen r1192 UNKNOWN-origin scope; it is not a new universal claim about arbitrary future authority families.

## Multiplicity and ambiguity

Duplicating an independent candidate cannot create selected status because only an existing productive selection handoff emits an observation. Duplicating equal-byte producers also cannot create branch-specific identity: r1192 has already reduced equal-state provenance to the intersection of certain receipts.

No global ranking, first-wins rule, rare-state rule or corpus-conditioned uniqueness participates in disposition classification.
