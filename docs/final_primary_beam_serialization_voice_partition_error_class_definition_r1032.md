## Frozen causal error class

The class is named `final_primary_beam_serialization_voice_partition_fragmentation`.

A member requires all of the following causal facts:

- an existing canonical primary-beam authority requires visible beam continuity for the exact occurrence cohort;
- an existing notation-voice authority proves one semantic notation voice for those exact occurrences;
- the final serialized representation partitions the occurrences across multiple technical voice/serialization channels;
- final renderer-visible primary-beam continuity is weaker than the canonical required continuity at a boundary created by that technical partition;
- no canonical beam boundary or semantic notation-voice boundary independently authorizes that visible break.

This definition is about a causal mismatch between semantic notation ownership and technical serialization ownership. It is not defined by a particular project, measure, rhythmic location, number of groups, preceding pause, pitch contour, register, numeric voice labels, or corpus rarity.

## Explicit exclusions

The following properties have no class-defining authority without a separate independent causal proof: leading rests, exact beat positions, exactly three groups, exact note/group counts, measure-edge placement, project/measure identity, page/system position, source-id values, pitch/register pattern, and uniqueness in the current corpus.

In particular, a property is not admitted merely because adding it removes a counterexample or leaves one known witness.
