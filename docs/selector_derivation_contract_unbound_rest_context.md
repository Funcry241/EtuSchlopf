## Meaning

This is an authority-closure failure, not proof that a visible rest is musically
wrong. The affected new mutation is Unknown and cannot be permitted from the
missing premise. Existing obligations remain protected. Independently complete
groups remain independent; duplicate observations do not create authority.

The class is independent of renderer capacity. A single-voice work can have
unbound rest context; a fully bound multivoice work can exceed capacity. The
accepted partwide_renderer_channel_capacity contract is unchanged. Classification
of that class still requires its own full projection and consumer resource proof.

## Necessity review

An exact occurrence/obligation distinguishes coincident material. An independently
authorized musical responsibility distinguishes a musical course from a reused
technical channel. Explicit licensed coverage distinguishes rhythmically required
silence from mere lack of observations. Role/staff segments distinguish permitted
presentation from arbitrary neighboring choices. Actual creation/continuation
ancestry prevents later geometry from inventing an origin. Completeness prevents
unobserved hidden sounding material or existing rests from becoming new silence.
Each premise is required by the dependent decision, not by a corpus witness.

The preservation/issuance requirements are in canonical_rest_context_contract_v1.md.
There is no productive classifier or repair in this Take and no automatic new
global release gate. A later implementation must refer to this accepted unchanged
definition and separately justify its true authority/repair scope. Neither this
definition nor its executable model grants a capability to invent musical courses.
