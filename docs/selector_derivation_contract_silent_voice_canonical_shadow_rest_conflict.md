## Causal definition

This class exists when a productive SilentVoice visible-coverage materialization turns cursor-only forward representation into visible rest notation and the resulting rest is, under the already-bound frozen voice relation, simultaneously a positive member of the canonical FinalVisibleRestRole auxiliary-shadow-bookkeeping class.

The defect is not the existence of a forward-only lane by itself. It is the contradiction between the later materializer and the already established canonical rest-role truth: one owner materializes visible musical silence while the canonical role owner/readback says that the same visible carrier is technical shadow bookkeeping.

A candidate is not a member merely because another sounding voice exists on the same staff. The bound canonical shadow-rest predicate remains the deciding positive conflict evidence. Likewise, a full-timeline forward lane is not automatically technical and must not be globally suppressed.

If the proposed materialization produces no canonical shadow-rest member under the same bound voice plan, this error class does not apply. Legitimate independently required silent voices remain outside the class.

## Necessity review

1. A productive forward-to-visible-rest materialization proposal is necessary because the class concerns creation of visible notation, not preservation or elision of an already visible rest.
2. The same frozen voice binding is necessary because raw XML voice labels alone are not musical identity.
3. Positive membership in the existing canonical shadow-bookkeeping predicate is necessary because mere overlap with another voice is insufficient to distinguish a true independent silent voice from technical bookkeeping.
4. Absence of stronger independently bound musical-silence evidence is necessary so that a future repair does not override a genuinely independent voice merely because it has geometric overlap.
5. Cursor and sounding invariants are explicitly insufficient because they prove technical serialization safety, not that a newly visible rest has a musical obligation.

## Evidence requirements for later repair scope

A later selector-sensitive repair must reference this contract byte-unchanged from an accepted parent.

The preferred repair direction is to prevent or reject only those SilentVoice coverage replacements whose resulting visible rest carrier is positively classified by the existing bound canonical shadow-rest role predicate. The canonical predicate must be reused or consumed as one truth; a second approximate overlap heuristic must not be invented in the SilentVoice planner.

A later repair may be narrower when required by existing writer ownership, available bound voice-plan evidence, byte-local materialization safety or preservation invariants. It may not disable all SilentVoice coverage merely because some candidates conflict.

The existing committed-state readback remains fail-closed and must not be weakened. It is the independent persisted proof that no forbidden shadow-rest carrier survived or was reintroduced.

Normative tests derived later must be synthetic and corpus-independent. Relocation, renaming, irrelevant pitch changes and independent duplication must not alter the local class decision.
