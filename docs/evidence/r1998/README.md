# Windows-Abnahme r1998

Der abgenommene Stand **EtuSchlopf 0.10.1839 r1998** erzeugte unter Windows 15 Partituren mit insgesamt 59 PDF-Seiten. Alle Projekte meldeten vollständige Ausgaben und Exitcode 0. Clippy lief erfolgreich. Die Strict-Tests meldeten 3.173 bestanden, null fehlgeschlagen und vier übersprungen.

Im oberen System von Bach BWV 847, Takt 25, verbindet ein gemeinsamer Balken F–D–C. Das H trägt sein eigenes Fähnchen. Beide Achtelpausen bleiben sichtbar. Die Regel überprüft ursprüngliche Balkengruppen, vollständige Zeitintervalle und die Fortsetzung der musikalischen Linie. [Mathematische Herleitung](../../MATHEMATIK.md#kapitel-6-3)

Der Vergleich mit r1997 ergab 58 pixelgleiche Seiten bei 144 dpi. Die Abweichung auf Bach-Seite 3 liegt im geprüften Takt und betrifft 860 Pixel. Alle 15 Master-MusicXML-Dateien sind bytegleich. Die einzige Abweichung in den Render-MusicXML-Dateien sind vier technische Stimmenzuordnungen im geprüften Bach-Takt.
