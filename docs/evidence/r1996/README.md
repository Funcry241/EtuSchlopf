# r1996 · MuseScore-Lizenz für Satzfix

r1996 dokumentiert die Lizenz der Satzfix-Erweiterung für MuseScore Studio 4.7.5.
Der datierte Änderungshinweis und der vollständige MuseScore-Lizenztext
gehören zur [Renderer-Dokumentation](../../../tools/satzfix_renderer/README.md).
Die ausführbaren Anweisungen im Patch und im Header entsprechen r1995.

Die [Renderprüfung von r1995](../r1995/README.md) beschreibt den musikalischen Stand.
Der Windows-Build des gepatchten Renderers und dessen Quellpaket sind offen.
