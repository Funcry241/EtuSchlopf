# Windows-Abnahme r2020

Der Windows-Vollkorpus von **EtuSchlopf 0.10.1839 r2020** endete mit Exitcode 0. Alle 15 Projekte erzeugten ihre Ausgaben neu. Die Notenausgabe umfasst 58 PDF-Seiten. Build und Clippy Strict melden Exitcode 0, Clippy Strict meldet null Warnungen. Der Vollkorpus verwendete den exakt an Quelle, Toolchain und Binärdatei gebundenen Prüfbeleg des vorausgegangenen Schubert-Einzellaufs. Dort bestanden 3.236 Tests bei zehn übersprungenen Tests. [Notenbilder](../../examples/README.md#notenbilder) · [PDF-Quellen](score-source.tsv) · [Prüfsummen](score-sha256.txt)

Beide MusicXML-Ausgaben aller 15 Projekte sind bytegleich zum Windows-Vergleichslauf r2015. Die 58 Seiten stimmen in der gezeichneten Ausgabe mit der bisherigen r2014-Galerie überein. Der Quellsnapshot für r2020 enthält 2.288 Dateien. Die Bestandsliste und die Prüfsummen binden die Rekonstruktion für den Windows-Build an die abgenommenen Quellbytes.

Der r2020-Audit weist in der lokalen Schubert-Vorschau sieben Gruppen mit 14 Halsänderungen nach. Der Windows-Vollkorpus bestätigt die bisherige Notenausgabe. Für die produktive Halskorrektur steht der Schlussnachweis für das gemeinsam ausgegebene MusicXML/PDF-Paar im Windows-Lauf aus.
