This repair consumes the unchanged accepted causal definitions. It neither
requires every optional bridge to survive nor describes extension members as
original beam members. The original positive groups, their membership and their
source roles remain unchanged. E050 keeps its beam-only footprint; withdrawal
still refuses a connection whose bound final assignment remains split or unknown.

The existing canonical original-beam voice alignment may include the actual
adopted extension as an atomic resource of its original component. Its complete
resource image includes every fragment of the participating sources/attacks and
physical chord attachments. The pre-lane notation relation is captured from the
existing authenticated notation owner; XML labels never fill missing authority.
No new source/role/beam identity is issued. Missing custody or semantic relation
refuses this additional path. Existing original-only decisions retain their
pre-existing prerequisites.

Scope is limited to complete single-measure, single-staff resource images with
canonical staff-compatible source roles. These limits concern transport and
presentation safety, not class membership. Existing target alternatives come
only from the original component. All occupancy, bystander rest, chord, source
closure and full partwide import checks remain mandatory. Conflicting shared
resources withdraw every interacting proposal; there is no ranked winner and
independent duplicated groups retain independent admission.

from its original-group identities. Late rebinding requires that same live
connection custody. At the existing typed scalar-write continuation, only the
proof-backed connection may transport its already admitted voice change.

all connected heads must share the admitted final label, and complete occurrence
