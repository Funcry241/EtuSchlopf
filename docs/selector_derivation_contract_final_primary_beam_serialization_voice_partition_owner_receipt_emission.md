## Measurement-only owner-boundary emission

r1052 does not define a new repair selector or a new Beam rule. The governance role is `error_classification` because the changed shared owner source is selector-sensitive under Take-Change-Control and the emitted evidence will later participate in classification of the already frozen parent error class.

The productive decision remains the existing `structural_metric_beam_hierarchy_plan(...)` result. Exactly one existing owner invocation creates the BeamPlan. The boundary receipt is then projected from that same plan without a second planning call and without any fail-closed veto introduced by receipt construction. Existing consumers continue to consume the same contained BeamPlan.

The receipt is intentionally identity-free. Binding it to the already-closed occurrence/proof-chain identity is reserved for a separate later audit take. No receipt field or local multiplicity can grant write authority, and adding an independent candidate or observation cannot change the emitted receipt for an existing owner invocation.
