This is the prerequisite observational portion of the accepted class, not a
positive classifier or repair. The complete class is not narrowed to the
supported cost probe. Every emitted frame states ClassMembership=UNKNOWN,
EarlyRegisterProposalBinding=UNKNOWN and Feasibility=NOT_PROVEN. Numerical
improvement does not fill those missing facts. An unavailable observation is
not a negative classification and does not affect musical processing.

The existing actual clef input and the actual incumbent cost constants cross
one explicit read-only diagnostic edge at the original planner entry. No private
musical plan, occurrence identity, writer token or decision is exported. The
new audit reads the XML already available at that diagnostic boundary. It uses
the unchanged lower-domain TemporalPart and pitch/ledger observers. The existing
staff-2 convention is the supported piano-domain coordinate of those observers,
not a newly learned selector; unsupported domains remain unavailable.

All proposals in a part observation are alternative complete versions of that
same part course, including unaffected surrounding pitches, clefs and carry.
Only their numerical count and lowest cost are reported. No proposal coordinates,
plan, approval, chosen source, writer input, or materialized variant returns to
the caller. Independent parts and repeated input calls are never deduplicated,
ranked together, or used to suppress each other's observations.

The observer reports ledger maximum, per-object sum and the same graded ledger
pressure as the existing clef objective, with explicit visible-object denominator.
Current transition, redundancy, short-excursion weights and short-attack limit
come directly from the existing owner; no productive cost constant changes.
True octave mapping changes and reminder cues are reported separately and do
not acquire a new weight. There is no three-ledger cutoff or forced treble rule.

The experiment explores existing representation-boundary intervals, not arbitrary
note, phrase or measure selectors. Constant bass/loco and treble/loco mappings
are numerical counterfactuals, not a ban on octave or double-octave notation.
A required high register can remain strictly cheaper with its octave display.
Existing ties, simultaneous notes, hidden carriers, rests, beams and following
carry remain in source; unsupported temporal input or overflow is unavailable.
The mathematical cut check is not proof of tie, beam or writer feasibility.
Those remain independently unproven, as the emitted status states.

No positive runtime class distribution is claimed from these observations.
A later classification must bind the actual early register proposal and retained
occurrences in a shared authority epoch before changing UNKNOWN. A later musical
repair additionally requires its own justified scope, original materializers,
receipts, adoption and final persisted-state/PDF proofs. This take preserves
all musical decisions, outputs, existing authorities, costs and gates.
