# StructureLayoutCapabilityGapAudit r176

## Parent and scope

Parent: accepted EtuSchlopf v0.10.1839 r175 `WavPitchRescueSelectorStructuralClosure`.

r176 is `AuditOnly`. It introduces no musical mutation, no layout-policy change, no writer, no threshold and no new phrase detector. Its purpose is to close the pre-research inventory before any structure-aware layout experiment is allowed.

## Why this take exists

The current tree already contains two mature but separated capability families:

1. `audit_only::phrase_boundary_evidence` owns canonical, lane-preserving, multifamily structure evidence and relative grouping observations.
2. the horizontal layout stack owns final-notation facts, one typed `HorizontalLayoutPlan`, global page/system planning and one StructuralWriteAuthority materializer.

The research question is therefore not whether EtuSchlopf can invent a new phrase engine or a new layout planner. It is whether existing structure evidence can later add stable information to an already admissible layout choice.

r176 proves what is present and what is still missing before r177 may construct any counterfactual projection.

## New report section

`STRUCTURE-LAYOUT-CAPABILITY-GAP-AUDIT-NO-MUTATION`

It records, without changing policy:

- availability and coverage of existing phrase/structure evidence;
- existing phrase role/group counts;
- the committed-source initial horizontal plan shape before renderer-feasibility productive selection;
- bound plan/fact cardinality and decision provenance;
- page-local `2+3 <-> 3+2` system-partition counterfactual opportunities;
- reusable capabilities;
- derivable capabilities;
- integration gaps;
- authority/reachability distinctions;
- the narrow meaning of the existing `phrase_boundary_role=conflict` state;
- the exact r177 experiment boundary;
- forbidden duplicates and out-of-scope visual grouping.

## Literature evidence contract

r176 records the research status separately from runtime authority:

- multiscale musical structure: `THEORETICALLY_SUPPORTED`;
- horizontal line-breaking as an optimization problem: `ENGRAVING_ESTABLISHED`;
- Structure -> system-break preference: `ENGINEERING_HYPOTHESIS`;
- conventional structure-aware boundary spacing: `ENGINEERING_HYPOTHESIS`;
- explicit vertical visual-grouping whitespace: `OUT_OF_SCOPE` for the conventional-layout route.

These labels authorize no threshold, weight or write. They prevent an engineering hypothesis from being reported later as musical ground truth.

## Authority distinction

The existing phrase evidence owner has no local XML writer. Nevertheless its `PhraseNotationIntentProjection` already has a transitive productive consumer in the accepted phrase-slur final-notation transaction.

Therefore r176 distinguishes conceptually between:

- local write authority;
- transitive productive reachability;
- decision authority;
- materialization authority.

A future Structure->Layout projection may be writer-free locally while still influencing a productive plan downstream. That influence must never be hidden behind the label `audit_only`.

## Existing conflict is not general ambiguity

The existing role `conflict` is emitted only when authorized tonal closure and authorized tonal anti-closure coincide. It is not a general aggregate disagreement across rhythm, melody, continuation, novelty, parallelism and tonality.

r176 therefore does not reuse `role=conflict` as the future ambiguity state and does not add a replacement score.

## Local counterfactual testbed

The current layout representation makes a controlled first r177 experiment possible without changing page count or system count:

`[2 measures] | [3 measures]` versus `[3 measures] | [2 measures]`

or the symmetric reverse, restricted to adjacent systems on the same page.

r176 only counts these opportunities in the committed-source initial plan before renderer-feasibility productive selection. It does not select either partition and does not materialize an alternative. Binding raw structure evidence to the later renderer-final-selected plan remains an explicit integration gap for r177.

Independent pre-take inspection of the accepted r175 ten-project export found exactly 30 such final-layout cases across the corpus. That external observation motivates the audit but is not embedded as a threshold or expected per-project count.

## r177 gate

r177 is permitted only to add a read-only counterfactual projection that:

- observes exact measure-boundary structure context;
- preserves lane identity rather than majority-voting voices;
- compares the current and alternative local break positions without a musical scalar score;
- keeps existing geometry/demand evidence separate from structure evidence;
- records break-sensitive notation dependencies, including phrase slurs, without using them to move a break;
- performs no XML or PDF write.

If these conditions cannot be met without a new musical truth, second planner or writer path, the research route stops.
