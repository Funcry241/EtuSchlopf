## Measurement-only classification boundary

This contract implements no new productive selector and introduces no repair authority. `SelectorChange: yes` records that the generic audit code contains selector-sensitive classification control under the existing Take-Change-Control grammar; it does not grant productive selection semantics.

The parent error-class contract is the already accepted `final_primary_beam_serialization_voice_partition_fragmentation` definition. This take leaves that parent byte-identical and only adds ordered evidence about where a persisted Level-1 Beam state first changes across real authorized Render-MusicXML writer boundaries.

The observation applies uniformly to every project and every successful authorized Render-MusicXML write. Exact structural before-after identity is an ambiguity guard, not a witness selector. A delta row cannot veto, repair, rank, release, mutate, or create Beam authority.

## Causal feature necessity review

1. Exact structural before-after note identity is necessary because a Beam-state comparison across different notes would not identify a writer-caused state transition.
2. A real authorized writer boundary is necessary because the purpose is to localize the persistence boundary at which existing Beam state changes, not to reconstruct hypothetical transformations.
3. Level-1 Beam-state inequality is necessary because unchanged Beam state supplies no divergence evidence.
4. Project, measure, pitch, voice label, ordinal position and corpus rarity are not causal selectors; they may be reported or used only inside exact identity binding and cannot decide whether an independent candidate is eligible.
5. Full membership in the frozen parent error class remains unresolved until its independent canonical-authority, exact-occurrence and renderer-visible geometry obligations are satisfied.
