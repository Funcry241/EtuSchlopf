CausalFeature: an asynchronous UI resource response is retained or displayed without binding it to the requested observation session and resource address, so a superseded request or a different session may supply the visible PDF.
CausalFeature: a failed resource request remains indistinguishable from an active request, while unrelated observation messages can repeatedly trigger the failed retrieval.
NonCausalContextExcluded: score identity, concrete project names, absolute measure positions, musical content, number of projects, stage duration and distribution in an evaluation corpus do not define this error class.

Session and resource strings are addresses, not musical selection features.
Renaming them consistently, relocating requests, reordering observations and
duplicating independent resources must preserve each resource's local result.
Equal addresses within one session may share one outstanding read. A new
session is a distinct address even when a project label is reused.

This definition concerns the read-only Watch resource view and HTTP read
boundary. It grants no music, file-write, repair or release authority. r1681
contains no PDF implementation of this class; a later take must consume this
unchanged definition from its accepted parent.
