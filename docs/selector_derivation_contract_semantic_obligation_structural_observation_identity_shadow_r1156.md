## Derivation from the accepted parent class

The accepted r1152 parent freezes `semantic_obligation_accounting_failure` before this Rust code exists. That class explicitly requires two later evidence layers: structural observation of persisted facts and identity/correspondence evidence that is never reconstructed from physical coordinates. r1156 implements only the first read-only measurement surface for those requirements.

The selector-sensitive branches in `semantic_obligation_structural_observation_shadow.rs` are therefore evidence-classification decisions, not musical or productive selection. XML node kinds and attributes determine which structural facts are projected. Missing parse or identity evidence stays unavailable. Explicit element IDs are counted as observed bytes but are not treated as semantic lineage. No branch can select a repair candidate, authorize a writer, create an obligation, discharge an obligation or affect release.

The parent error-class contract is consumed byte-unmodified from r1152. This implementation contract does not narrow the causal class to E2, E6, E7, a measure, a staff, a voice, a pitch, a corpus count or any known witness. Its scope is exactly the evidence boundary already required by the parent class.

## Multiplicity and duplication

Observation is per persisted artifact and per schema-defined event. Duplicating one independent structural event adds its own observation rows and may alter the artifact projection hash and counts; it does not change whether another event is observed and cannot create semantic occurrence or lane correspondence. No scorewide uniqueness or ranking participates in the decision.

There is no productive write in this take. `CandidateDuplicationProbe: required_before_productive_write` therefore remains a future precondition rather than a write authorization. Any later productive consumer must prove its own duplication invariant before obtaining write authority.

## Authority boundary

r1156 is `AuditOnly`. The Final Report owner already receives persisted Master and Render MusicXML bytes; the new module reads those bytes and appends one evidence section. It introduces no bridge from private productive lineage state, no selector or writer capability, no MusicMutation, no repair/recovery path and no release veto.

The result is allowed to say that semantic occurrence or lane correspondence is unavailable. That unavailability is an architectural measurement result and must not be filled by Staff/Voice/Onset/Pitch matching.
